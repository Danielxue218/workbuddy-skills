# 02 · 证明前景推演：关联分析法两层审查

> 本文件是引擎的**核心**（也是最难的一块），对应六阶段动线的**阶段三**、九步法的 **⑤⑥⑦**（为三段论
> 小前提构造证明前景面；⑧事实认定的预判归 `03`）。它承 `01` 交来的**要件清单**，产出**决定性要件排序**与**各要件的证明前景**，交 `03`。
>
> **一句话转译**：法官版在此"审查合理性、分配责任、认定事实"；**律师版在此"预判每一站的法律合理性、
> 预判每个争议要件的证明前景"**。一切结论是概率与区间，不是判决（`00-method` §3.1）。

---

## 0. 本文件的位置与产出

- **输入**（自 `01`）：请求权基础群、抗辩(权)群（带二分）、**要件清单**（带类型 / 证明责任种子 / 证明标准 /
  争议状态初判）、诉讼地位（原告 / 被告）、材料成熟度。
- **两层引擎**（关联分析法，`00-method` §1.8 / §3.3）：**第零层程序站（可受理性）**→ 第一层法律审查（不吃
  证据）→ 争点识别 → 第二层证明前景审查（吃证据）→ 决定性要件排序。
- **产出**：五案型分诊结论、有效争点清单、各争议要件的证明前景、**决定性要件排序**、证明缺口（交检索 /
  取证清单）。

---

## 1. 引擎骨架：五站 × 两层

关联分析法把审查分为**若干站**，归入**两层 + 前置程序站**（正源，`00-method` §1.8）：

```
第零层            第一层 · 法律审查（不吃证据）        第二层 · 事实审查
┌──────────┐   ┌───────────────────────────┐   ┌──────────────────┐
│ 程序站    │→ │ 原告站 → 被告站            │→ │ 证据站            │→ 主文站
│（可受理性）│   │ （反抗辩→再抗辩 迭代）      │   │ 证明前景推演       │  结果研判(03)
│不合法→裁定 │   │ 有理性 / 重要性审查         │   │（仅对有争议要件）  │
│驳回起诉    │   └───────────────────────────┘   └──────────────────┘
└──────────┘           └─ 五案型分诊：多数案子在此定论，无须进第二层 ─┘
```

**【规则 · 内在结构（每一站内部）】** 每项请求权基础按"**积极要件 → 消极抗辩**"检视；抗辩依"**权利未发生
→ 权利已消灭 → 权利阻止**"次序（对应 §1.5 四分、§1.7 二分）。检视三层（王泽鉴）：请求权**已发生 → 未消灭
→ 可行使**。

---

## 2. 第零层 · 程序站（可受理性审查，Prozessstation）

**【规则】** 在实体法律审查之前，先过**程序站**（正源 Relationstechnik 的第一站，`00-method` §1.8）——
预判诉是否**合法可受理**：**管辖、当事人适格、诉的利益、重复起诉 / 既判力（一事不再理）、其他程序与诉讼
要件**。
- **可受理性不成立 → 预判"裁定驳回起诉"（程序判决）**，与实体上的"判决驳回诉请"是**两种不同结果**，须分列。
  此时后续实体审查失去意义（如正源：程序站不合法则原告 / 被告 / 证据站均无须再审）。
- *（理据 · 防翻车）* 跳过程序站，正是"拿一份单方起诉状就断'原告全胜'"的病根。任何预判在给实体结论前，
  必须先过这一关；主体链（挂靠 / 转包 / 实际施工人）与管辖尤其要先厘清（承 `01` 的主体 / 管辖标记）。

---

## 3. 第一层 · 法律审查（有理性审查，不吃证据）

**核心问法**：**假定陈述方所说全部为真**，其主张在法律上能否成立（有法律合理性 / Schlüssigkeit）？
此层**不需要任何证据**，材料再薄也能跑，是"材料不充足也有产出"的保证。

### 3.1 逐站审查
- **① 原告站** —— 假定原告陈述为真，其诉请是否被请求权基础的**全部积极要件**支撑。**审查不限于对原告
  有利的内容**：原告陈述中若含**权利未发生 / 权利已消灭**事由，也要检视；若含权利消灭事由（如自陈被告已
  履行），还须检视有无**请求权维续（anspruchserhaltend）事由**（如履行有瑕疵）将其挽救。
- **② 被告站** —— 假定被告陈述为真，其抗辩是否有法律合理性。
- **③ 第二原告站（反抗辩 Replik）** —— 原告对被告抗辩的反抗辩是否有法律合理性（含"抗辩排除"类型）。
- **④ 第二被告站（再抗辩 Duplik）** —— 被告的再抗辩是否有法律合理性。

### 3.2 检出项
**【规则】** 第一层须检出两类致命缺陷（不吃证据即可发现）：
- **主张缺口**（主张责任 / Behauptungslast）：某积极要件，陈述方**根本没有主张**对应事实 → 该要件不成立。
- **自曝式败诉**：陈述方把自己讲进一个**权利消灭 / 妨碍**事由，却**无维续事由**挽救 → 不必等对方出手，自败。

*（理据）* 抗辩权（如时效）与抗辩不同：即使原告陈述中提到"被告可行使时效抗辩"，也**不足以**据此认定原告
诉请无合理性 —— 因为抗辩权行使与否是被告的权利事项（§1.7），须留待被告站 / 第二层。

### 3.3 五案型分诊（法律审查先于事实审查，多数案子在此定论）
**【规则】** 第一层跑完先分诊（`00-method` §3.3）；程序站已在前（§2，不合法→预判裁定驳回起诉）：
- **原告诉请无法律合理性**（主张缺口 / 自曝消灭无维续）→ **预判原告败诉**，不进第二层。
- **被告抗辩无法律合理性**，而原告诉请有合理性 → **预判原告胜诉**，不进第二层。
- **原告诉请有合理性 且 被告抗辩有合理性 且 双方陈述不一致** → **进入第二层**（证据），就有争议要件评估
  证明前景。
- （多请求权基础时：须**每一个**请求权基础的诉请都有合理性、被告抗辩都有合理性，才就该基础进第二层；
  只要有**一个**请求权基础的诉请有合理性而对应抗辩无合理性，原告即可就该基础预判胜诉。）

### 3.4 立场读数
- **原告向**：确保己方每个积极要件在陈述层面**已主张、无自曝**；预判被告站可能站住的抗辩。
- **被告向**：优先在原告站找**主张缺口 / 自曝**（一击即可使原告在法律层面败诉，无须进证据）。

---

## 4. 争点识别（有效争点 vs 伪争点）

**【规则】** 进入第二层前，先识别**有效争点**：**只有指向"某要件事实能否获得满足"的争议，才是有效争点。**
双方吵得凶但不指向任何要件事实的，是**伪争点**，剔除。**【规则】** 同时**固定无争议事实**（含自认 / 免证
事实，§1.6）—— 它们不进第二层，直接作"默示满足"处理。争点 = 待进入证明前景推演的"有争议且有法律意义
的要件"。

---

## 5. 第二层 · 证明前景审查（有据性审查，吃证据）

**进入条件**：仅五案型分诊判定"进第二层"者；**仅对有争议且有法律意义的要件**（无争议 / 免证的不进）。

### 5.1 四步推演（每个争议要件）
**【规则】** 逐要件走四步（`00-method` §1.6 / §3.3）：
1. **定标准** —— 该要件适用哪级证明标准：默认**高度盖然性**；涉**欺诈 / 胁迫 / 恶意串通 / 口头遗嘱 /
   口头赠与**→**排除合理怀疑**；程序性事项→较大可能性。
2. **分责任** —— 该要件的**客观证明责任**归谁（规范说：发生要件→请求人；妨碍 / 消灭 / 受制→相对人）。
3. **评前景** —— 负责任方**现有证据能否达到该标准**；以及**对方（反证方）能否将其拉回真伪不明**（见 §5.3
   不对称）。
4. **定后果** —— 真伪不明时，由负**客观证明责任**方就该要件承担败诉。

### 5.2 证明前景的修正因素（务必计入，不得遗漏）
**【规则】** 评前景时叠加以下因素，它们可显著改变某要件的证明前景：
- **自认 / 拟制自认**（§1.6）：对方明确承认，或经询问不置可否 → 该事实无须证明（对我方是重大利好 / 对己方
  是"说错一句输官司"的风险）。
- **书证提出命令 + 证明妨碍**（证据规定第45–48条）：关键书证在**对方控制**下且属五种法定应交情形的，可申请
  提出命令；对方**无正当理由拒交 → 可推定我方主张的书证内容为真**；**恶意毁证 → 可推定我方待证事实为真**。
  —— 这是"证据在对方手里"时**把不利转为有利**的武器，须在证明前景中显性评估，并转 §8 取证 / 申请清单。
- **鉴定**：工程、医疗、知产等案件，"打官司即打鉴定"；关键要件（如工程质量、工程量、因果关系）的证明
  前景，往往取决于鉴定的可行性、启动主体与结论倾向 —— 须单列评估。
- **免证事实**（§1.6）：法定无须证明者直接标"已满足"。

### 5.3 本证 / 反证的不对称（预判核心武器，民诉法解释第108条第2款）
**【规则】** 负举证责任方的**本证**须使事实达**高度盖然性**；不负举证责任方的**反证，只需把事实拉回
"真伪不明"，即可使负举证责任方败诉**。
- **被告向**：不必把相反事实证到高度盖然性，**只需评估己方能否"动摇确信、制造真伪不明"** —— 这是被告端
  天然的证明前景优势，应优先利用。
- **原告向**：须警惕自己的本证被对手"搅浑"到真伪不明的风险，预先补强。

## 6. 决定性要件识别与排序

**【规则】** **决定性要件 = 有争议 × 客观证明责任在我方 × 现有证据未达该要件的证明标准（或对手足以将其
拉回真伪不明）**。三条同时命中者，即本案胜负所系。

**【规则】** 对识别出的决定性要件**排序**（构成"胜负手清单"，供 `03` 与交付物使用），排序维度：
- 对结果的**决定力**（该要件不成立是否直接导致败诉）；
- **证明前景的差距**（离证明标准有多远）；
- **可补强性**（缺口是否可通过取证 / 鉴定 / 书证提出命令消除 —— 接 §8）。

*（注：决定性"要件"是原告须证成的积极要件；诉讼时效等致命"抗辩权"是决定性"抗辩 / 风险"，二者分列，
不得混入决定性要件，§1.7。）*

---

## 7. 律师版转译：从"认定"到"预判"

**【规则】** 法官版第 7–8 步是"分配责任 + **认定**事实"；律师版在此是"评估证明前景 + **预判法官会如何
认定**"：
- 一切结论是**概率 / 区间**（"该要件证成前景较高 / 存疑 / 低"），不是"已认定"；
- 预判"法官会如何认定"须结合**类案裁判口径**（详见 `03` 与 `retrieval-spec.md`），但类案只作校准、不冒充
  确定结论；
- 心证公开（法官义务）在律师版无直接对应，但"法官会形成何种心证"正是本层要预判的对象。

---

## 8. 材料不充足下的运行

**【规则】** 两层结构对材料成熟度自适应，不停机：
- **第一层**（法律审查）**总能跑完**：主张缺口、自曝、五案型分诊，只需陈述、不需证据。
- **第二层**（证明前景）随材料深浅伸缩：证据充分则给实前景；不足则将该要件标为**"证明前景待定 + 缺口"**，
  并生成**取证 / 鉴定 / 书证提出命令 / 检索**事项，转 `01` / 检索方案与办案清单（阶段五）。
- 材料越薄，越要显性标注"此为法律层面预判，证据层面待补"，绝不假装已认定（诚实纪律，`epistemics.md`）。

## 10. 本文件不是什么

- **不预判对手的诉讼行为**：被告是否真会提时效抗辩、会交什么证据文书、会不会提管辖异议 —— 是 `03`（攻防链
  的**行为预判**）；本文件只在法律层面审查"若提出，是否有合理性"。
- **不做结果研判、不合成焦点、不接类案**：结果区间、最坏情形、法官焦点、类案裁判倾向 —— 均在 `03`。
- **不放立场打法**：立场（攻防着力点）只在阶段六产出。
- **不认定事实、不下判决**：律师版只"预判证明前景"，一切是概率 / 区间。
