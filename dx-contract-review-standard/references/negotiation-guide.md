# 谈判优先级清单生成规则 negotiation-guide.md

> **场景极度垂直 · SOP 极度精简 · 交付极度优雅**
>
> 本文件定义如何将审查报告(report-template.md)中的风险发现转化为**可执行的谈判策略文档**。
>
> 谈判优先级清单是标准审查四件套中的**作战手册**——律师带上谈判桌的那份文件。

---

## 核心特性(v1.0.0)

| 特性 | 说明 |
| --- | --- |
| Tier 条目呈现 | **三列对照表**(原文 \| 建议 \| 谈判话术),避免堆叠段落的阅读疲劳 |
| 修改建议改动字 | `**...**` 包裹的部分渲染为 `#EE0000` 正红 |
| Plan B 呈现 | 黑字段落 + `**关键参数**` 红字标注(如金额比例、时限) |
| 规则来源 | 每条 Tier 项标注 `标准清单 / Playbook 覆盖 / 清单外发现` |
| Tier 标识 | 扁平 ■ 方块(红/橙/绿功能色,不用 emoji 圆球) |
| 一级/二级标题 | Word 内建 `Heading 1/2` 样式(导航窗格可见) |
| 封面 | 包豪斯风格 · NEGOTIATION PRIORITY CHECKLIST · 浅蓝 #1387C0 · 单外层表格 |

### Tier 条目结构(三列对照表)

```
Tier 1-01   ■ {问题标题}

对应审查报告:风险 01  ·  对应清单:C025  ·  规则来源:标准清单

┌────────────────────┬────────────────────┐
│  条款原文            │  修改建议(含红字)    │
├────────────────────┼────────────────────┤
│ "乙方应就本合同..."  │ "乙方应就**因其过错**..."│
├────────────────────┴────────────────────┤
│  谈判话术(合并 talking_points)            │
└──────────────────────────────────────────┘

对方可能反驳:{opponent_rebuttal}
应对要点:{counter_response}
Plan B 对冲方案:{plan_b,含 ** 红字标注}
```

## 定位说明（先读这一节）

### 一、谈判清单在四件套中的角色

| 文件 | 核心定位 | 使用场景 |
| --- | --- | --- |
| 合同概要 | 客观信息提取 | 决策前快速了解合同 |
| 审查报告 | 风险分析与修改建议 | 向内部或客户汇报审查结果 |
| **谈判优先级清单** | **谈判策略与桥面条款** | **谈判桌上的作战手册** |
| 业务流程图 | 履约流程可视化 | 理解合同执行路径 |

**审查报告回答"这份合同有什么问题"。谈判清单回答"怎么把这些问题变成谈判筹码"。**

### 二、谈判清单 vs 审查报告的差异

同一个风险发现在两份文件里的呈现方式完全不同：

**审查报告里**（分析性）：
```
【风险 3】■ 中风险 · 违约金条款不对等

▎合同原文："甲方违约支付 5%，乙方违约支付 20%"
▎风险说明：双方违约金比例差异 4 倍，超出常规行业惯例，
  实际争议中法院可能依据民法典第 585 条酌减。
▎修改建议：建议将双方违约金统一为 10%-15%。
```

**谈判清单里**（策略性）：
```
【Tier 2-2】违约金不对等（原审查报告风险 3）

▎谈判立场：建议协商调整，争取对等违约金
▎桥面条款：{可直接发给对方的替代条款文字}
▎谈判话术：{3 个可在谈判桌上使用的论据}
▎对方可能反驳：{对方在这个问题上可能的立场}
▎应对要点：{我方的反反驳思路}
▎退让底线：差异不超过 2 倍（即甲方 10%、乙方 15% 可接受）
▎交换筹码：{可以用来换取对方让步的 Tier 3 事项}
```

### 三、风险等级与 Tier 的强制映射

本 Skill 采用**风险等级与 Tier 分档的强制映射**，简化律师判断：

| 风险等级 | Tier 归属 | 处理原则 |
| --- | --- | --- |
| ■ 高风险 | Tier 1 必须回绝 | 不解决则不签约 |
| ■ 中风险 | Tier 2 建议协商 | 重点争取修改 |
| ■ 低风险 | Tier 3 可以接受 | 作为谈判让步筹码 |
| ✓ 正常 | 不进入清单 | - |

**特殊情况**（仅在审查报告"清单外发现"章节可出现）：
- 清单外发现如经律师判断为核心问题，可破格归入 Tier 1
- 此类破格必须在清单中特别标注"【破格归档】"

## Tier 分档详细规则

### ■ Tier 1：必须回绝（Deal Breaker）

**入选条件**（满足任一）：
- 审查报告中标记为 ■ 高风险的条款
- 涉及合同效力的根本性问题（如主体不适格、标的违法、条款被法律认定无效）
- 可能导致无限责任或不可控风险敞口的条款（如无上限连带责任、无限索赔权）
- 缺失的、必须补充的核心条款（如无争议解决条款、涉及个人信息但无 DPA）

**处理原则**：
- 不解决则不能签约
- 不可作为让步筹码
- 如对方坚持不修改，**必须升级**（暂停谈判，向合伙人或客户汇报）

**谈判策略**：
- 谈判桌上第一时间提出
- 用法律依据而非商业立场说服对方（民法典第 X 条、司法解释、裁判规则）
- 准备 **Plan B 对冲方案**：如对方无法完全修改，可通过其他条款补偿（如增加担保、提高违约金、增加保证期等）

### ■ Tier 2：建议协商（Strong Preference）

**入选条件**（满足任一）：
- 审查报告中标记为 ■ 中风险的条款
- 条款偏离行业惯例但有谈判空间
- 对我方权益有实质影响但非致命的条款
- 原属 ■ 高风险但经商业判断可接受适度妥协的条款

**处理原则**：
- 重点争取修改
- 可在获得其他补偿条件下适当让步
- 每项设有明确的**退让底线**，超过底线则升级为 Tier 1

**谈判策略**：
- 用"行业惯例""双方公平""对双方都好"等中性论据
- 配合交换策略——用 Tier 3 的让步换取 Tier 2 的争取

### ■ Tier 3：可以接受（Concession Candidate）

**入选条件**（满足任一）：
- 审查报告中标记为 ■ 低风险的条款
- 条款对我方略有不利但影响有限
- 属于"改了更好，不改也能接受"的条款
- 属于规范性瑕疵（表述不规范、格式不美观等）

**处理原则**：
- 作为谈判筹码，用这些条款的让步换取 Tier 2 的争取
- **即使让步，仍有底线**：超过底线则改变 Tier 归属（如 Tier 3 项被对方进一步压缩，可能变成 Tier 2 需要重新谈判）

**谈判策略**：
- 不主动提出（避免暴露为筹码）
- 对方如提出类似调整，顺势接受并换取其他让步
- 作为"慷慨让步"塑造谈判氛围

## 每档条目的完整字段

每个谈判项都按以下七个字段结构化（Tier 1 有八项，多一项 Plan B）：

### 字段 1：条目编号与标题

格式：`【Tier {档位}-{序号}】{问题标题}（原审查报告风险 {序号}）`

示例：`【Tier 1-2】乙方承担无限连带责任（原审查报告风险 1）`

清单中的条目按 Tier 1 → Tier 2 → Tier 3 顺序排列，各 Tier 内按严重性排序。

### 字段 2：当前条款内容

摘录合同中的原文，精简版，不超过三行。必须加引号（中文引号）。如条款太长，用省略号截取关键部分。

示例：
```
▎当前条款（第 12.2 条）：
"乙方应就本合同项下任何违约行为向甲方承担无限连带责任，
该责任不受本合同其他条款关于责任上限的约定限制。"
```

### 字段 3：建议修改语言（桥面条款）

给出**具体的替代条款文字**，可以直接发给对方。语言风格要求：
- 正式、客观
- 避免对抗性措辞
- 使用合同原有的表述习惯（甲乙方、条款引用格式）
- 不使用"建议增加""建议完善"等空话

**桥面条款格式**：
```
▎桥面条款：
"乙方应就本合同项下因其过错违反本合同导致甲方损失的行为承担
赔偿责任。除故意或重大过失外，乙方的赔偿责任总额以本合同总金额为上限。"
```

**特殊情况**：涉及商业判断（价格、期限等）无法给出具体条款文字时，明确标注"需律师根据交易背景判断"并说明判断方向。

### 字段 4：谈判话术要点

给出 **3 个**可在谈判桌上使用的论据或话术方向，帮助律师在谈判时阐述修改理由。

**话术要求**：
- 从对方也能接受的角度出发（"这样约定对双方都更公平""这是行业通行做法""法院可能判决无效"）
- 避免激烈对抗性措辞
- 至少 1 个法律依据论据 + 1 个商业合理性论据 + 1 个行业惯例论据

**格式**：
```
▎谈判话术（3 点）：
1. 【法律依据】民法典第 585 条明确规定违约金过分高于实际损失的，
   法院可酌减。当前 4 倍差异的违约金条款在实际争议中难以全额支持。
2. 【商业合理性】对等的违约金更能体现双方履约的严肃性，
   不对等条款反而可能诱发对方不重视履约。
3. 【行业惯例】同行业类似合同的违约金约定通常在 10%-20% 区间，
   双方比例差异一般不超过 2 倍。
```

### 字段 5：对方可能反驳（新增字段）

预判对方在这个问题上可能的立场和反驳点。好的谈判准备是双向的——不只想我方要什么，还要想对方会怎么反对。

**格式**：
```
▎对方可能反驳：
- "我方是强势方，这是我们的标准条款，没有谈判空间"
- "我们公司的法务政策要求如此，无法变更"
- "这是为了应对你方违约风险设计的，如果降低会影响我们的决策"
```

### 字段 6：应对要点（新增字段）

对应"对方可能反驳"，给出我方的反反驳思路。

**格式**：
```
▎应对要点：
- 针对"标准条款"：要求对方提供类似行业的标准合同作对比；
  如对方无法提供，说明这是个性化要求而非行业标准
- 针对"法务政策"：建议由双方法务/律师直接对接，或要求
  对方提供法务政策的原文
- 针对"对冲我方违约风险"：提出以增加担保/保函形式替代，
  比违约金更可靠
```

### 字段 7：退让底线

**所有 Tier 都要设定退让底线**，这是本次升级的重要改动——之前版本只有 Tier 2 设定底线，导致 Tier 1 和 Tier 3 的边界在谈判中模糊。

| Tier | 底线含义 |
| --- | --- |
| Tier 1 | 对方完全不修改时触发**升级机制**（暂停谈判，汇报合伙人或客户决策） |
| Tier 2 | 我方最低可接受的修改幅度；超过底线则**升级为 Tier 1** |
| Tier 3 | 我方让步的底线幅度；超过底线则**升级为 Tier 2** 需要重新谈判 |

**格式**：
```
▎退让底线（Tier 2-2 违约金不对等）：
- 最优结果：双方违约金均为 15%（完全对等）
- 可接受结果：甲方 10%，乙方 15%（差异 1.5 倍）
- 底线：差异不超过 2 倍
- 超过底线：升级为 Tier 1，暂停谈判
```

### 字段 8（仅 Tier 1）：Plan B 对冲方案

当 Tier 1 项对方坚持不改时，考虑其他方式对冲风险。这是**资深律师的谈判逻辑**——不是"改不了就不签"，而是"这里改不了，那里补回来"。

**Plan B 的常见方式**：
- 增加担保（保证金、保函、母公司保证）
- 提高违约金
- 增加保证期/质保期
- 限制责任上限
- 增加保险要求
- 缩短合同期限
- 增加退出条款

**格式**：
```
▎Plan B 对冲方案（Tier 1-2 无限连带责任）：
如对方坚持保留无限连带责任条款，可考虑以下对冲方式之一：
- 对冲方式 1：要求对方增加履约保证金（合同金额 20%），
  以保证金为限承担责任
- 对冲方式 2：要求对方母公司/关联方出具连带责任保证函，
  明确责任上限为合同金额 2 倍
- 对冲方式 3：设置保证期限（如 2 年），超过保证期后不再承担连带责任
- 如以上均不接受，触发升级机制
```

## 谈判策略总结（Negotiation Strategy）

本章在清单末尾独立成节，综合呈现整份清单的谈判策略。

### 一、优先事项

```
本合同共有 {X} 个必须回绝项、{Y} 个建议协商项、{Z} 个可接受项。

必须回绝项清单（按紧迫性排序）：
1. 【Tier 1-1】{问题}（影响：{具体影响}）
2. 【Tier 1-2】{问题}（影响：{具体影响}）
...

谈判应优先解决以上 {X} 个必须回绝项。
```

### 二、交换策略（多对多，非一对一）

之前版本只支持"让步 A → 换取 B"的单对单交换，实务中交换策略往往是组合拳：

```
交换策略矩阵：

让步组合 A：Tier 3-1 + Tier 3-3 + Tier 3-5
→ 换取：Tier 2-1 + Tier 2-2

让步组合 B：Tier 3-2 + Tier 3-4
→ 换取：Tier 2-3

说明：
- 让步组合 A 优先使用，因为其中 Tier 3-1 和 Tier 3-5 是对方重视的事项
- 让步组合 B 作为备用，换取的 Tier 2-3 可以进一步缓解对方立场
```

### 三、谈判节奏

```
第一阶段（开场）：
- 展示审查的专业性，提出全部修改意见清单（Tier 1 + Tier 2 + Tier 3 全部）
- 说明我方的原则立场，但不逐条展开，留出对方研读时间

第二阶段（聚焦）：
- 对方回应后，按 Tier 1 → Tier 2 → Tier 3 顺序逐步协商
- Tier 1 项目如对方坚持不改，评估是否启用 Plan B
- Tier 1 所有项不接受（无论是否启用 Plan B），暂停谈判并向委托人汇报

第三阶段（交换）：
- Tier 2 项目进入协商时，配合交换策略——用 Tier 3 的让步换取 Tier 2 的争取
- 涉及多对多交换的，先完成组合 A，再评估组合 B

第四阶段（收尾）：
- 记录所有已达成的修改点
- 未达成共识的项目列入"待决事项"清单
- 约定下一轮谈判或决策流程
```

### 四、升级机制

明确在哪些情况下需要"暂停谈判，向合伙人或委托人汇报"：

| 触发条件 | 升级对象 | 升级紧迫度 |
| --- | --- | --- |
| 任一 Tier 1 项对方完全不同意修改 | 合伙人或委托人决策 | 24 小时内 |
| 多个 Tier 2 项触达退让底线 | 合伙人讨论 | 本次谈判后 |
| 对方提出新的、清单未覆盖的重大问题 | 合伙人讨论 | 立即 |
| 对方在 Tier 3 项要求超出我方底线 | 团队内部评估 | 本次谈判后 |

## 格式要求

### 文档规范

- **字体**：
  - 正文：宋体（小四，12pt）
  - 标题：宋体加粗（一级 16pt / 二级 14pt），应用 Word 内建 Heading 1 / Heading 2 样式（导航窗格可见），黑色
- **字号**：一级标题 16pt，二级标题 14pt，正文 12pt
- **行距**：1.5 倍行距
- **页边距**：上下 2.54cm，左右 3.17cm（Word 默认 A4）
- **页眉**：`{合同名称} · 谈判优先级清单`
- **页脚**：`审查编号：{对应审查报告编号}` + 页码

### 颜色规范（与审查报告统一）

采用通用"交通灯色系"，与审查报告保持色系一致，不使用个人品牌色：

以 `visual-style-guide.md` 为唯一权威来源。正文全局黑字，仅以下元素着色：

| 元素 | 色值 | 说明 |
| --- | --- | --- |
| ■ Tier 1 符号 | `#FF0000` | 正红（仅 ■ 方块着色，文字标签黑色） |
| ■ Tier 2 符号 | `#FF9900` | 标准橙（仅 ■ 方块着色） |
| ■ Tier 3 符号 | `#00A650` | 正绿（仅 ■ 方块着色） |
| 建议文本中 `**...**` 改动字 | `#EE0000` | 正红（Word 修订工作习惯） |
| 桥面条款"建议修改为"引导语 | `#0070C0` | 专业蓝（Office 标准色） |
| 退让底线突出 | `#FF0000` | 正红 |

风险/Tier 标注一律使用 **■ 方块 + 文字标签**，不使用 emoji。

### 篇幅控制（分档差异化）

之前版本要求"控制在 3-5 页以内"不现实——复杂合同 Tier 1 就可能有 10 项。本次升级改为分档差异化：

| 章节 | 篇幅要求 |
| --- | --- |
| Tier 1 必须回绝项 | **无页数限制**（每个 Tier 1 项目都必须完整展开） |
| Tier 2 建议协商项 | 每项控制在 1 页内，总计不超过 10 页 |
| Tier 3 可以接受项 | 每项控制在半页内，总计不超过 5 页 |
| 谈判策略总结 | 2-3 页 |

## 质量检查清单

生成谈判清单后自检：

### 内容完整性
- [ ] 所有 ■ 高风险都进入 Tier 1，所有 ■ 中风险进入 Tier 2，所有 ■ 低风险进入 Tier 3
- [ ] 每个条目都有桥面条款（Tier 3 可以是方向性建议）
- [ ] 每个条目都有 3 点谈判话术
- [ ] 每个条目都有"对方可能反驳"和"应对要点"
