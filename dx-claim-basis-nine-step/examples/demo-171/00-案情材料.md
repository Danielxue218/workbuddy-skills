# 案情材料 · 恒和国际商务会展中心工程款纠纷（中天视角）

> 以下是**中天建设（承包人）代理律师在提起诉讼前掌握的材料**。用于本 demo 的判决前推演，
> **不含任何判决结果**。

---

## 一、当事人

- **我方 · 中天建设集团有限公司**（承包人 / 拟起诉的原告）。
- **对方 · 河南恒和置业有限公司**（发包人）。**已进入破产程序**（破产申请于 2018-04-10 受理，由管理人接管）。
- **相关第三人**：
  - 德汇工程管理（北京）有限公司 —— 受恒和委托、对案涉工程作结算审核、出具《审核报告》。
  - 王峰波 —— 恒和法定代表人（签署《审核报告》时在任）。

## 二、事实经过（围绕各笔给付组织）

1. **签约**：2012-09-17、2013-06-26，中天与恒和先后签订两份《恒和国际商务会展中心工程建设工程施工合同》，
   合同价款暂定 4 亿元；2013-06-25 恒和向中天发《中标通知书》，中标价 570,959,342.49 元。约定"结算后 28 天
   支付工程款"。补充条款：因恒和或政府部门等非中天原因致本项目未获中州杯等奖项的，合同约定的总价款优惠
   点 4% 调整为 0%（即不下浮）。
2. **施工**：中天依约进场施工，已施工至 39 层。中天**放弃**第 39 层已施工部分及以上未完工部分的工程款主张。
3. **已付款**：恒和已向中天支付工程价款 **9500 万元**。
4. **结算审核**：2014 年，恒和与德汇公司签《建设工程造价咨询合同》，委托其作**结算审核**。2014-11-03，
   德汇出具《审核报告》，**恒和法定代表人王峰波签字并加盖恒和印章**，中天亦签字确认；载明完成对审后工程
   造价 **394,478,042.29 元**。《单方造价测算分析表》与《审核报告》数据一致。
   - 据此，欠付工程价款 = 394,478,042.29 −（第 39–43 层未完工造价 11,049,994.4）− 已付 95,000,000 =
     **288,428,047.89 元**。
5. **停工**：2015 年 1 月前后停工（约 2015-02-05）。
6. **建设手续**：截至纠纷时，恒和对案涉工程**仍未取得建设工程规划许可证、施工许可证**等手续。
7. **主张优先受偿权（发函方式）**：中天先后于 2014-12-01（向焦作中院提交在建工程拍卖联系函）、2015-08-04
   （向恒和）、2016-05-05（向洛阳中院）主张优先受偿权。
8. **拟起诉时点**：2017-04-26。

## 三、我方拟提出的诉请（原告 · 中天）

1. 确认恒和欠付工程价款 **288,428,047.89 元**（诉请一 · 工程款本金）。
2. 确认恒和应付逾期利息 / 违约金（自 2015-03-01 起按约定标准计算）（诉请二 · 利息）。
3. 停工损失 18,304,546.82 元（诉请三 · 损失）。
4. 在上述债权范围内，对恒和国际商务会展中心工程折价 / 拍卖价款**享有优先受偿权**（诉请四 · 优先受偿权）。

## 四、可预判的对方抗辩（判决前预估，待对方上桌校正）

- **程序**：本案为破产债权确认之诉，恒和可能主张"管理人审查为前置程序、中天径行起诉程序违法，应驳回起诉"。
- **T4 数额 / 结算依据**：恒和可能否认《审核报告》——形式（德汇无资质 / 跨省未备案 / 无签章）、内容
  （工程未竣工未验收、楼层数与出具日矛盾、含 2500 万元垫资补偿、未按约下浮 4%）、**公章系伪造、与第三方
  恶意串通**；并据此**申请造价鉴定**。
- **T3 质量**：主张工程未完工、未经验收、质量未查明，不应确认应付工程款。
- **诉请二 利息**：主张合同无效、利息等同违约金不应支持；中天无资质进场有过错。
- **诉请四 优先受偿权**：主张行使已过 **6 个月除斥期间**（起算点主张竞争：竣工日 / 结算日 2014-11-03 /
  停工日 2015-02-05），且主张须以诉讼方式行使、发函无效；2500 万元垫资补偿不属优先受偿范围。

## 五、材料与缺口（律师自评）

- **在手**：两份施工合同、《中标通知书》、《审核报告》（王峰波签字盖章）、《单方造价测算分析表》、
  付款凭证（9500 万）、施工月报表、三次主张优先受偿权的函件、恒和破产受理裁定。
- **缺口 / 待核**：竣工验收资料缺（工程未验收）；建设手续缺（规划 / 施工许可证）；对方是否提质量鉴定申请
  待定；优先受偿权起算点认定待定。
