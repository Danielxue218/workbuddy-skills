# 复杂测试案例 · 「星海商业综合体」工程款纠纷（虚构）

> 本材料供测试本 skill 用。**当事人、公司、个人、金额、时间均为虚构**；文中各方援引的条号是**当事人主张**，
> 不代表已核验。引擎运行时应对其中的条号照常挂 `【待核验】`。

---

## 一、当事人与主体链（复杂，务必先厘清）

- **发包人 · 宏图置业有限公司**（业主 / 开发商）。项目负责人 **李某**（在多份签证、结算文件上签字、加盖
  "宏图置业星海项目部"印章）。宏图置业**已被债权人申请破产，法院尚未裁定受理**。
- **总承包人 · 泰盛建工集团有限公司**（有施工总承包资质，经招投标程序"中标"）。
- **实际施工人 · 周某**（自然人，无施工资质）。周某以**借用泰盛资质**名义进场，与泰盛另签《内部承包
  协议》，实际组织人员、机械完成主体工程。**拟起诉的原告。**
- **专业分包 · 华锐幕墙工程有限公司**（幕墙工程分包，与泰盛签《专业分包合同》，含"**背靠背**"付款条款）。
- 其他：材料供应商若干、农民工若干（工资已部分拖欠）。

〔主体链要点〕宏图置业 →（总包）泰盛 →（违法转包 / 借用资质）周某；泰盛 →（专业分包）华锐。
周某与宏图置业**之间无直接合同**。

## 二、时间线（关键节点）

1. **2021-03**：宏图置业将"星海商业综合体"（商业＋写字楼）发包给泰盛，签《建设工程施工合同》，
   中标价 **3.6 亿元**，约定"按月付进度款、竣工验收合格后 60 日内结清"。
   —— 但该项目**属依法必须招标的项目，实际未招标 / 招标程序存在重大瑕疵**（效力存疑）。
2. **2021-04**：泰盛与周某签《内部承包协议》，约定周某"自负盈亏、上缴管理费 3%"，实际施工由周某负责。
3. **2021-05 至 2023-01**：周某组织施工，完成地下室、主体结构、部分机电，**施工至外立面阶段**。
   施工期间，宏图置业项目负责人**李某**在周某提交的 **17 份《工程量签证单》、3 份《阶段性结算表》**上
   签字并加盖"**星海项目部**"印章，累计确认已完成工程量对应价款约 **2.4 亿元**。
4. **付款**：宏图置业累计支付 **1.35 亿元**——其中约 8000 万付给泰盛、约 5500 万**直接付给周某**
   （周某据此主张宏图明知并认可其实际施工人身份）。
5. **2023-02**：因宏图置业资金链紧张、拖欠进度款，**工程停工**。停工时未竣工、未整体验收。
6. **2023-04**：宏图置业**擅自使用**已完工的商业裙楼部分（部分商铺开业招商）。
7. **2023-06**：周某向宏图置业、泰盛分别发《催款函》，并在函中"**主张就工程折价 / 拍卖价款优先受偿**"。
8. **2023-09**：部分楼层被第三方检测机构报告指出"**存在混凝土强度不足 / 裂缝**"（宏图据此主张质量不合格）。
9. **2024-11**：周某**拟提起诉讼**（停工至今约 21 个月），一并起诉宏图置业与泰盛。
10. 宏图置业的破产申请于 **2024-10** 被债权人提出，**尚未裁定受理**。

## 三、拟主张的诉请（原告 · 周某）

1. **工程款本金**：确认欠付工程价款约 **9,050 万元**（周某算：已确认 2.4 亿 − 已付其可归部分 − 未完工部分）。
2. **利息**：自 2023-04-01 起按 LPR 计至实际清偿。
3. **停工损失**：约 **860 万元**（人员、机械闲置、材料保管）。
4. **优先受偿权**：就"星海商业综合体"折价 / 拍卖价款在工程款范围内优先受偿。
5. 请求**泰盛与宏图置业在欠付工程款范围内承担责任**（突破合同相对性 / 代位）。

## 四、各方主张（只登记，不裁断）

### 周某（原告 / 实际施工人）
- 合同虽可能无效，但工程**主体已完成、部分已被使用**，应参照约定折价补偿（主张民法典 793 `【待核验】`）。
- 李某签字＋项目部章的 17 份签证、3 份结算表，**足以确认工程量与价款**；宏图直接付款 5500 万，
  印证其认可周某实际施工人身份。
- 主张实际施工人可**突破相对性向发包人主张**（建工解释一 43 `【待核验】`），并对宏图**代位**行使泰盛的到期
  债权（建工解释一 44 / 民法典 535 `【待核验】`）。
- 优先受偿权以**发函方式在期限内主张**；起算点应自"应付款之日"（主张 2023-04 之后），未过 18 个月。

### 宏图置业（被告 / 发包人）
- **程序**：周某与宏图**无合同关系**，起诉宏图**主体不适格**，应驳回起诉；且项目在破产申请中，应中止 / 移送。
- **合同无效**：未招标 + 违法转包，合同无效，周某作为实际施工人**无权主张优先受偿权**（主张建工解释一 35
  主体限缩 `【待核验】`）。
- **签证 / 结算无效**：李某**越权**，"星海项目部"章**非宏图备案公章**（疑似私刻）；且周某与李某**恶意串通、
  虚增工程量**（主张按**排除合理怀疑**审查，民诉法解释 109 `【待核验】`），故 2.4 亿不能作数，应**造价鉴定**。
- **质量**：部分楼层强度不足 / 裂缝，**工程质量不合格**，要求质量鉴定并扣减、拒付。
- **优先受偿权**：即便享有，**已过 18 个月除斥期间**（主张自"应付款之日"起算，发函无效、须诉讼方式），
  且停工损失、利息**不属优先受偿范围**（主张建工解释一 40 `【待核验】`）。

### 泰盛（被告 / 总承包人）
- 对周某：确认存在《内部承包协议》，但主张周某**超支、质量扣款**，对欠付数额有异议（部分自认、部分否认）。
- 对宏图：主张宏图欠付总包款，**"背靠背"不成立于己**（款项已由宏图直接付周某部分）。

### 华锐幕墙（案外 / 关联）
- 另案向泰盛主张幕墙分包款；泰盛以《专业分包合同》"**背靠背**"（宏图未付则泰盛不付）抗辩。
- 华锐主张：宏图为大型企业、华锐为中小企业，**背靠背条款无效**（主张 2024 年最高法关于"背靠背"批复 `【待核验】`）。

## 五、在手材料与缺口（律师自评）

- **在手**：总包合同、内部承包协议、17 份签证单、3 份结算表、付款凭证（含直付周某 5500 万）、催款函
  （含优先受偿权主张）、第三方质量检测报告、宏图破产申请材料、专业分包合同（背靠背条款）。
- **缺口 / 待核**：招标程序材料（是否应招未招）、"星海项目部"印章的备案与真伪、李某授权范围、竣工验收资料
  （未验收）、工程量与造价的**独立结算 / 鉴定**（**无双方结算协议**）、优先受偿权应付款之日的认定。

## 附 · 本案要测引擎的哪些关节（供缪验收对照，非案情）

1. **N0 主体 / 管辖**：专属管辖（建设工程）；周某诉宏图**主体适格**（实际施工人对发包人）；破产未受理下的程序处理。
2. **程序站（→裁定驳回起诉）**：宏图"主体不适格 / 破产中止"抗辩，防"单方材料→全胜"。
3. **合同效力**：未招标＋违法转包→无效→**民法典 793 参照有效**路径（切换 T1）。
4. **T4 数额＝真·第一决定性要件**：**无结算协议**（与 demo-171 相反！），签证 / 结算的效力被"越权＋私刻章＋恶意
   串通"三重攻击 → 证明前景低、**造价鉴定成焦点**。测引擎能否识别 T4 为决定性要件、且**不被拉高**。
5. **证明标准陡增**：恶意串通虚增工程量 →**排除合理怀疑**；测引擎能否把该事实的标准单独抬高。
6. **举证责任分层 + 擅自使用**：宏图擅自使用裙楼 → **推定质量合格**（建工解释一 14）与质量抗辩的对冲。
7. **主体链与请求权基础切换**：实际施工人**突破相对性（43）/ 代位（44·535）**，主体与基础都变。
8. **优先受偿权**：实际施工人**是否享有**（主体限缩）＋**除斥期间起算点**争议＋发函 vs 诉讼行使方式＋**范围**
   （利息 / 停工损失不属，第 40 条）。
9. **抗辩 vs 抗辩权二分**：合同无效 / 质量（依职权审）vs 诉讼时效 / 除斥期间（须主张）。
10. **背靠背条款**：2024 批复下大企业对中小企业"背靠背"无效 —— 关联争点、非封顶指针。
11. **结果区间**：判决支持 / 部分支持 / 判决驳回诉请 / **裁定驳回起诉**四种出路都真实在候，测最坏情形叠加。

> 期待引擎输出：接案卡（五轴，标满缺口 / 边界旗标）→ 六阶段研判（T4 决定性、优先受偿权除斥期间与主体双风险、
> 恶意串通排除合理怀疑）→ 三图（矩阵红标 T4＋除斥期间；焦点汇聚"签证效力 / 优先受偿权 / 主体适格"；
> 区间带最可能"部分支持"、最坏"判决驳回诉请"甚至"裁定驳回起诉"）。
