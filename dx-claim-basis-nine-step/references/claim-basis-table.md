# 案由 → 请求权基础 对照表

> `00-method.md` §1.4 **接驳层**的落地：引擎以**民事案由**（律师的母语、也是**类案检索**最强的钥匙）
> 进入个案，经由本表被"播种"出据以推理的**请求权基础群**。这是一个**数据文件**，不是方法文件 ——
> 它是本 skill 可迭代的**灵魂数据**，对应合同审查 skill 里的 `checklist.md`。律师校验、扩充它；引擎读取它。
>
> 其结构**忠实于邹碧华《要件审判九步法（新注版）》（人民法院出版社，2021）附录「请求权、抗辩（权）
> 基础备考表」** —— 民事案由 ｜ 诉讼请求 ｜ 请求权基础 ｜ 抗辩权主张 ｜ 抗辩权基础 —— 并为"律师预判"
> 场景增强。

## 0. 核验纪律（先读，且不可妥协）

一旦有一个条号出错，本表的价值即刻归零。因此：

- **【规则】每一条法条 / 司法解释援引，都带核验标签。** 无例外。
  - `[✓核验 YYYY-MM-DD]` —— 已于该日对照一手 / 权威来源确认。
  - `【待核验】` —— 出自模型知识，**尚未确认**；在被输出**依赖之前**，必须（由缪或经检索）核验。
  - `[数据库·须核验]` —— 由已连接的法律数据库 MCP 返回；仍须向律师展示以待确认（依 `epistemics.md`）。
- **【规则】绝不编造条号或案号。** 未经确认的数字一律 `【待核验】` —— 分析给出**方向**
  （"查建工司法解释一关于利息的条文"），绝不给伪造的精确援引。（这正是我们拒斥的翻车方式。）
- **【规则】案由只做种子，绝不封顶**（依 §1.4 非封顶规则）。每个条目的「竞合 / 关联 / 跨法律关系」
  字段，正是为阻止本表把检索困在案由自身的法律关系里而设。
- **【规则】版本时效。** 条号以民法典时代为准。凡对某司法解释是否**现行有效**存疑，标 `【待核验】`
  并转入时效核验 —— 司法解释常有修订（如建工司法解释历经 2004 / 2018 / 2020 三版）。
- **【规则】必标规范类型。** 每条援引规范标注 主要规范（请求权基础）/ 防御规范 / 辅助规范，
  以免把防御规范误当请求权基础（§1.5）。

## 1. 条目字段（每个案由条目的 schema）

每个条目以 **案由（+ 典型诉讼请求）** 为键，含以下字段：

1. **案由** —— 《民事案件案由规定》的正式名称（+ 层级 / 上位案由）。
2. **典型诉讼请求** —— 所求的具体给付（一个案由可含数项，逐项列出）。
3. **请求权基础** —— 按诉讼请求分列，每条含：条号 · 规范类型 · 核验标签 · 一句话要旨。
   分为 主给付请求权基础 / 从请求（利息·违约金，及依附于主债权的**担保性 / 优先性权利**）。
4. **构成要件分解** —— 大前提骨架：主张方须证成的各项要件。
5. **证明责任与证明标准分配** —— 依 §1.6：各要件由何方证（客观证明责任）+ 适用哪级证明标准（默认高度盖然性；欺诈 / 胁迫 / 恶意串通 / 口头遗嘱 / 口头赠与→排除合理怀疑；程序事项→较大可能性）+ 标注免证事实（证据规定第10条）。
6. **典型抗辩 / 抗辩权** —— 对手可能的防御，每条含：性质（否认 / 抗辩 / 抗辩权）·
   依职权审 或 须当事人主张 · 抗辩权基础（条号 + 标签）· 举证责任。
7. **决定性要件提示** —— 通常"有争议 × 客观证明责任在原告 × 证明前景存疑"的那些要件
   （该案由反复出现的胜负手；是先验，非定论）。
8. **竞合 / 关联 / 跨法律关系** —— 非封顶指针（竞合的基础、关联请求、主体突破）。
9. **类案检索要点** —— 该案由的争点导向检索关键词。
10. **边界标记** —— 任何确认之诉 / 形成之诉成分，标出边界（00-method §5）。
11. **主体适格与管辖提示** —— 主体链（挂靠 / 转包 / 实际施工人 / 名实不符）与管辖须先厘清（N0）；
    错则 T1 与主体适格落空。

## 2. 打样条目 · 建设工程施工合同纠纷（请求支付工程款）

> 以此条目作模板。核验标签为实时状态：`[✓核验 2026-07-07]` vs `【待核验】`。
> 请缪确认【待核验】各项与要件分解。

### 2.1 案由
- **建设工程施工合同纠纷**（《民事案件案由规定》· 合同、准合同纠纷 项下 · 建设工程合同纠纷 之子案由）。
- 关联子类型：装饰装修合同、分包合同、（无效施工合同下的）实际施工人纠纷。

### 2.2 典型诉讼请求
1. 判令发包人支付工程款本金 ¥___；
2. 判令支付逾期付款利息 / 违约金；
3. 确认承包人对工程折价或拍卖价款享有优先受偿权（及其顺位）。

### 2.3 请求权基础（按诉讼请求分列）

**诉请一 · 工程款本金（主给付请求权）**
- **有效施工合同**：施工合同中的**工程价款条款本身**即为请求权基础（有效合同条款是请求权基础，§1.2）· 主要规范 · 结合 **民法典第788条**（建设工程合同定义）`[✓核验 2026-07-07]`。
- 价款无约定 / 约定不明：**民法典第510条、第511条**（合同补充与履行）`[✓核验 2026-07-08]` + 参照《建设工程价款结算暂行办法》等 `【待核验】`。
- **合同无效但工程经验收合格**：**民法典第793条**（参照合同关于工程价款的约定折价补偿承包人）`[✓核验 2026-07-07]` · 主要规范 · **合同无效情形的兜底请求权基础**。

**诉请二 · 利息 / 违约金（从请求）**
- 逾期付款违约责任：**民法典第577条**（违约责任一般条款）`[✓核验 2026-07-08]` + **合同约定的违约金 / 利息条款**（主要规范）。
- 无约定利息时的计付标准 / 起算：**建工司法解释（一）第26条**（利息计付标准：有约定从约定，无约定按同期同类贷款利率 / 全国银行间同业拆借中心 LPR）、**第27条**（利息起算时间：竣工 / 交付 / 结算 / 起诉日区分）`[✓核验 2026-07-08 · 第27条起算已核；第26条标准表述待缪逐字终核]`。

**诉请三 · 建设工程价款优先受偿权（从请求 · 依附于工程款债权的法定优先/担保性权利）**
- **民法典第807条**（建设工程价款优先受偿权，全文已核验）`[✓核验 2026-07-07]` · 主要规范。
- **成立要件 · 质量合格**：**建工司法解释（一）第38条**（建设工程质量合格→优先受偿成立）、**第39条**（未竣工的建设工程质量合格，就承建部分亦可优先受偿）`[✓核验 2026-07-08]`。
- **建工司法解释（一）第35条**（与发包人订立施工合同的承包人有权主张）`[✓核验 2026-07-07]`；**第36条**（优先于抵押权及其他债权）`[✓核验 2026-07-07]`；**第40条**（范围：利息 / 违约金 / 损害赔偿金不属优先受偿）`[✓核验 2026-07-08]`；**第41条**（行使期限最长18个月，自应当给付工程价款之日起算，通说为除斥期间）`[✓核验 2026-07-07]`。
- 主体限缩：**仅“与发包人直接订立施工合同的承包人”**享有；勘察人、设计人、转包/违法分包承包人、借用资质人、**实际施工人不享有** `[✓核验 2026-07-07]`。

### 2.4 构成要件分解（诉请一 · 工程款本金 · 有效合同情形）
- T1｜承包人与发包人之间存在**有效**的建设工程施工合同（或：合同无效但工程经验收合格→切换至793条路径）。
- T2｜承包人**已完成**约定工程并交付 / 具备交付条件。
- T3｜工程**质量合格**（或经竣工验收合格）。
- T4｜工程款**数额已结算或可确定**（竣工结算 / 审计 / 约定计价）。
- T5｜**付款条件成就**（约定付款期限届满 / 结算款应付之日届至）。
- T6｜发包人**未支付**该工程款。

### 2.5 证明责任分配（规范说 · 客观证明责任）
- **承包人（原告）** 就 **T1–T6 的权利发生要件** 承担客观证明责任（合同、竣工交付凭证、结算文件、催款记录等）。
- **发包人（被告）** 就下列**权利妨碍 / 消灭 / 受制要件**承担客观证明责任：已付款（权利消灭）、约定付款条件未成就（权利未发生 / 受制）、结算未完成或工程量不实（对数额的争执，回到主张方）。
- **质量的举证责任是分层的（高发争点，务必分清）**：**竣工验收合格**属工程款请求权的**积极要件 T3，由承包人举证**；而**验收合格之后主张存在质量缺陷 / 保修责任以减损或拒付**，属**权利妨碍 / 减损抗辩，由发包人举证**（常需鉴定）。不得把两层压成一句“质量由谁证”。
- **证明标准**：本案由各要件（T1–T6）原则上适用**高度盖然性**。但若一方主张**优先受偿权系发包人与承包人恶意串通、恶意抬高价款以损害抵押权人**，该"恶意串通"事实适用**排除合理怀疑**（民诉法解释第109条）—— 证明标准陡然抬高，是此类攻防的胜负关键。经生效裁判 / 有效竣工验收备案确认的事实，可主张为免证事实（证据规定第10条）。

### 2.6 典型抗辩 / 抗辩权（被告端 · 攻防链预判）
| 被告主张 | 性质 | 审查方式 | 抗辩权基础 | 举证责任 |
|---|---|---|---|---|
| 工程款已（部分）支付 | 权利消灭抗辩 | 依职权审 | — | 发包人 |
| 工程质量不合格 / 存在缺陷 | 权利妨碍 / 减损抗辩 | 依职权审 | 建工司法解释一**第11–14条**（核心：**第12条**承包人原因质量不合格→减价、**第14条**未验收擅自使用→推定合格）`[✓核验 2026-07-08]` | 发包人 |
| 工程量 / 结算数额有争议 | 否认（对数额的否认） | 随主张 | — | 争议部分回到主张方 |
| 付款条件（结算/期限）未成就 | 权利未发生 / 受制抗辩 | 依职权审 | 合同条款 | 发包人 |
| 施工合同无效 | 权利妨碍抗辩（但有793条兜底） | 依职权审 | 民法典第793条 `[✓核验]`（无效但验收合格仍折价补偿） | 发包人证无效事由；承包人证验收合格 |
| **诉讼时效抗辩** | **抗辩权** | **须当事人主张，法院不得依职权审、不得释明** | **民法典第188条**（普通诉讼时效3年）`[✓核验 2026-07-08]` | 发包人 |
| 同时履行 / 先履行抗辩权 | **抗辩权** | 须当事人主张 | 民法典第525（同时履行）/ 526条（先履行）`[✓核验 2026-07-08]` | 发包人 |

### 2.7 决定性要件 / 决定性抗辩提示（本案由高发胜负手 · 先验非定论）

> **要件 ≠ 抗辩，分列。** 决定性“要件”是原告须证成的积极要件；决定性“抗辩”是可致败诉的对立事由。二者不得混列（§1.5 / §1.7）。

**决定性要件（原告举证前景存疑处）：**
1. **T4 工程款数额（竣工结算 / 工程量）** — 举证责任在承包人，实务中最常因**缺竣工结算文件 / 工程量争议**而证明前景存疑。**通常是第一决定性要件。**
2. **T3 竣工验收合格** — 承包人的积极要件；发包人常以验收后质量缺陷抗辩（举证责任转发包人），鉴定往往决定成败。
3. **T5 付款条件成就** — “竣工结算应付之日”的认定，直接牵动利息起算与优先受偿权行使期限。

**决定性抗辩 / 风险点：**
- **诉请三的18个月行使期限（通说为除斥期间，不中止不中断）** — 属**权利消灭事由**（非要件）；一旦逾期，承包人**丧失**优先受偿权，是易被忽略而致权利消灭的风险点。
- **诉讼时效抗辩（抗辩权，须发包人主张）** — 对工程款本金债权，被告一旦有效主张且成立即可致败诉。

### 2.8 竞合 / 关联 / 跨法律关系（非封顶指针）
- **合同无效**：不走不当得利，走**民法典第793条**特别规则（验收合格→折价补偿）；793条是特别法，优先于不当得利一般条款。
- **实际施工人**：合同无效时的实际施工人，可依**建工司法解释（一）第43条**突破合同相对性向发包人主张（**通说限“在发包人欠付工程款范围内”**）`[主旨✓核验 2026-07-07 / 精确表述与限定条件待逐字核验]`；第44条 代位权路径 `[主旨✓核验 2026-07-07 / 表述待核验]`。此时**主体与请求权基础都变**，须切换分析线，不能被“施工合同纠纷”案由框死。
- **优先受偿权性质**：主流实务认定为**法定优先权 / 法定担保物权**，可适用民法典担保物权一般规定 `【待核验适用条款】`；对第三人（抵押权人）影响大，常成为**第三人撤销之诉**的攻击标的。
- **竞合处理规则（非封顶规则的操作落地）**：遇多个可能基础时，引擎须区分——**法条竞合**（规范排除，只适用其一）→ 择一适用；**请求权竞合**（数基础指向同一给付，如违约与侵权）→ 当事人择一主张，但**竞合的数项基础均可为裁判理由，当事人无“择一”义务**；**请求权聚合**（内容不同的数请求，如返还+赔偿）→ 可并列主张。此区分直接影响**诉请设计**（承接立场层 N6），故须在本层显性标出，不得被案由框死。

### 2.9 类案检索要点（依法发〔2020〕24号：相似性 = 基本事实 × 争议焦点 × 法律适用；按效力等级取用）
> 效力等级顺序：① 指导性案例（法院应当参照）→ ② 最高法典型案例及生效裁判 → ③ 本省高院参考性案例 → ④ 上级及本院生效裁判；除指导性案例外优先近三年。争点导向关键词：
- 数额/结算：`建设工程施工合同 工程款 竣工结算 工程量 举证责任`
- 质量抗辩：`工程质量不合格 工程款 扣减 鉴定`
- 无效情形：`施工合同无效 验收合格 折价补偿 793`
- 优先受偿权：`建设工程价款优先受偿权 18个月 除斥期间 起算 抵押权 顺位`
- 实际施工人：`实际施工人 突破合同相对性 发包人 欠付范围`

### 2.10 边界标记（scope flags）
- “**确认**优先受偿权成立 / 顺位”“**确认**合同无效”“**解除**合同”等，含**确认之诉 / 形成之诉**成分 → 该部分请求权基础分析法失灵，按 §5（00-method）flag 出边界，对**给付**部分照常分析。
- **主体核查**：发包人 / 承包人 / 实际施工人 / 挂靠关系须先厘清（工商与合同链），否则 T1 与主体适格判断落空。

## 3. 迭代说明（如何新增一个案由）

复制 §1 schema 的十一个字段，逐条填写；**每一条法条 / 司法解释先核验、后落表**，核验不了的一律
`【待核验】`。高频给付之诉案由优先建库（买卖合同、民间借贷、承揽合同、房屋租赁合同、股权转让款、
