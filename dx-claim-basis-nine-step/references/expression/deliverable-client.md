# 客户摘要 · 诉讼预判致当事人

> 这是给**当事人**看的摘要 —— 把律师版报告里的结论，转成当事人读得懂、拿得走的一份东西。它只回答
> 当事人真正在意的五件事：**这案子有多大可能赢、要花多少、有没有时限、要打多久、有哪些风险**，
> 末了给一句**综合建议**。技术过程（请求权基础、要件、证据组织、对手预判、攻防打法）**一律不进本摘要**。
>
> **两条底线先立**：(1) **不做胜诉承诺、不用绝对化措辞**（不出现"必胜""稳赢""必然败诉"）；
> (2) 本摘要对全部给付之诉通用，正文不写具体案由、不堆法言法语。

---

## 1. 客户版与律师版的根本不同（三点）

1. **受众是当事人（非专业人士）** —— 去术语、去条号、去学理，用大白话。
2. **只给结果维度，不给技术过程** —— 当事人要的是**可能性 / 成本 / 时效 / 周期 / 风险 + 一句建议**（§3），
   不是"我方主打哪个请求权基础""怎么把对方本证搅回真伪不明"。打法留在律师版。
3. **完整免责 + 知悉回执** —— 律师版只需一句免责；客户版是正式对客文件，须完整免责并留当事人**确认知悉**
   回执（§4）。

---

## 2. 呈现铁律（红圈所的底色：过程严谨，结果不承诺）

**【规则 · 前景绑定争议焦点，不甩孤立标签】** 表达赢面，**不写"胜诉可能性中等"这类孤立标签**（那是
低端风险告知书的做法）。专业做法是**把胜负绑定到本案的决定性争议焦点上，再作情景式表述**：
> "本案能否获支持，**主要取决于〔一句大白话讲清的关键点〕**。这一点若成立，您的诉请获支持的可能性
> **较大**；若不成立，则可能**部分获支持 / 被驳回**。综合最可能落在〔区间〕，须提醒您的最坏情况是
> 〔最坏情形〕。"
必要时以类案裁判倾向校准（"从类似案件看，法院多倾向……，仅供参考、个案有别"）。

**【规则 · 不夸胜、不隐最坏情形】** 最坏情形**必须讲**，且讲在明处 —— 宁可让当事人有心理准备，
不可报喜不报忧。

**【规则 · 成本与周期给法定锚点，不手感估摸】** 凡涉数字，**锚到法定依据**（成本→《诉讼费用交纳办法》，
周期→法定审限），并诚实说明变数（延长、不计入审限的期间），**不打包票、也不含糊敷衍**（详见 §3）。

**【规则 · 预判当事人的关注点】** 主动回应当事人一定会问的：**要不要打、能拿回多少、多久、花多少、
最坏会怎样**。

---

## 3. 五个维度 + 一句建议

**【规则】** 摘要按五维组织，每维一到三句、大白话；末尾给一句综合建议。

1. **可能性** —— 按 §2 铁律：绑定争议焦点 + 情景 + 区间 + 最坏情形。**不做胜诉承诺。**

2. **成本** —— 锚到法定依据：
   - **诉讼费**按争议金额（标的额）**依《诉讼费用交纳办法》分段计算**，**原则上由败诉一方负担**（部分胜诉
     按比例分担）；调解 / 简易程序**减半**。—— 这一项是**可估算的**，不是模糊量级。
   - **律师费**另行约定（本摘要不含报价）；如需**鉴定、评估、保全**等，另有相应费用。

3. **时效** —— **硬提醒**：您主张的权利有无诉讼时效 / 除斥期间，什么时候到，须在何时前主张，逾期的后果。
   （这一格关系重大，宁重复勿遗漏。）

4. **周期** —— 锚到**法定审限**，并说明为何实际可能更长：
   - **一审**：普通程序审限**六个月**（有特殊情况可依法延长）；简易程序**三个月**。
   - **二审**：对判决上诉审限**三个月**；对裁定上诉**三十日**。
   - **实际常更长**：**鉴定、公告、管辖异议、审计 / 评估等期间不计入审限**，有这些情形的案件时间会相应
     拉长；涉外案件不受审限限制。

5. **风险** —— 分三类点到为止：
   - **能不能赢**（实体风险）—— 证据是否充分、关键事实能否证成；
   - **程序风险** —— 管辖、时效、对方可能的程序动作（如管辖异议拖延）；
   - **能不能拿到**（执行风险）—— **一句场面话即可**：判赢之后能否实际执行到位，取决于对方的财产与
     履行能力，**需另行评估**（本摘要不含执行研判，请求权基础分析不涵盖执行）。

**综合建议（一句，承 stance §6 成本收益）** —— 结合上述，给一句**诉 / 调 / 撤 / 和解**的倾向性建议，
并注明"**这是建议，最终由您决定**"。不替当事人拍板。

---

## 4. 完整免责 与 知悉回执

**【规则 · 完整免责】** 客户摘要须附完整免责，核心几条（不堆砌）：
- 本摘要基于**您（当事人）提供的陈述与材料**作出；材料的真实、完整由您负责，如有新证据 / 新情况请及时
  告知，我方将据此更新判断。
- 本摘要是**判决前的专业预判，不是结果保证**；结论以**可能性 / 区间**表达。
- 案件结果**涉及法官的自由裁量**，最终裁判**非律师所能掌控**，请审慎参考。
- 本摘要**仅供您本人参考**，未经书面同意请勿向第三方出示、不得作为证据使用。

**【规则 · 知悉回执，且循实务顺序】** 风险不是把文件一放让当事人签字。**顺序**是：律师**先口头告知**
关键风险与最坏情形 → **再出示书面摘要** → **解读关键内容** → 当事人**确认知悉后签署**。摘要末尾留回执栏：
> *本人已阅读并知悉上述分析、风险与最坏情形。　当事人签字：＿＿＿＿　日期：＿＿＿＿*

**【规则】** 回执可**印在摘要末尾**，也可**另出一份《风险告知书》**单独签署（由律师按所内规范把握）；
本文件只保证回执内容齐备，不强制其载体形式。

---

## 5. 双时态 与 立场适配

**【规则】** 承接接案卡时态与立场：
- **前瞻（一审判决前）** —— "可能性"给一审预判。
- **回溯（二审 / 再审）** —— "可能性"改为**改判 / 维持的前景**，用大白话讲"原判决对您不利 / 有利在哪、
  能不能翻过来"；"周期"改用二审 / 再审的审限。
- **原告向** —— 侧重"能不能拿回 + 拿回多少 + 多久 + 花多少"。
- **被告向** —— 侧重"要赔多少 / 能不能不赔或少赔 + 有没有时效等可用的挡箭 + 最坏赔付"，语气重在
  控制损失预期。

- **交付**：交当事人。**不与律师版混发** —— 律师版含技术过程与打法，不给当事人。

---

## 7. 本文件不是什么

- **不含技术过程** —— 不写请求权基础、要件、证据组织、对手预判、攻防打法。
- **不做胜诉承诺、不绝对化** —— 不出现"必胜""稳赢""必然败诉"；一律预判 + 区间 + 最坏情形。
- **不做执行研判** —— 执行风险只作一句场面话提示，不实质分析。
- **成本 / 周期不手感估摸、也不编精确私产数字** —— 锚到法定审限与诉讼费办法；律师费报价另谈。
- **不含案由专属内容** —— 五维模板对全部给付之诉通用。

## 8. 模板（可套用）

> 大白话，去术语；举例一律抽象，不写具体案由。

```
【致〔当事人〕· 案件预判摘要】（前瞻 / 回溯 · 原告向 / 被告向）

一句话结论：本案能否〔达到您的目的〕，关键在于〔一句大白话讲清的决定性争议点〕。

一、赢的可能性
   这一点若成立，获支持的可能性较大；若不成立，可能〔部分获支持 / 被驳回〕。
   最可能的结果：〔区间〕。须提醒您的最坏情况：〔最坏情形〕。
   （如有类案：从类似案件看，法院多倾向……，仅供参考、个案有别。）
二、成本：诉讼费按标的额依法计算、原则由败诉方负担（调解/简易减半）；律师费另议；如需鉴定/保全另计。
三、时效【重要】：您的权利〔有/无〕时限；如有，须在〔时间节点〕前主张，逾期〔后果〕。
四、周期：一审普通程序约六个月（可依法延长）、简易三个月；二审约三个月。若涉鉴定/公告/管辖异议，
   相应期间不计入审限，实际会更长。
五、风险：能不能赢〔实体〕——…；程序——…；能不能拿到〔执行〕——判赢后能否执行到位取决于对方
   财产与履行能力，需另行评估。

综合建议：结合上述，建议〔起诉/调解/和解/暂缓〕——这是建议，最终由您决定。

免责：本摘要基于您提供的材料作出，是判决前预判、非结果保证；结果涉及法官自由裁量，非律师所能掌控；
仅供您参考，勿向第三方出示。
本人已阅读并知悉上述分析、风险与最坏情形。　签字：＿＿＿＿　日期：＿＿＿＿
```
