# 合同审查清单 checklist.md

> **本文件是整个 Skill 的灵魂。** 所有审查判断基于此清单执行。
>
> **场景极度垂直 · SOP 极度精简 · 交付极度优雅**
>
> 迭代方式:每次审查后发现的遗漏或不准确,直接修改本文件、新增条目,并在末尾"迭代记录"中登记。
>
> 定制方式:复制本 Skill 文件夹,将本文件替换为专用清单(如"股权转让专用清单""海商合同专用清单"),即为新的 Skill 变体。

---

## 可选字段(v1.0.0)

> 本清单每条检查项支持两个**可选字段**,用于标记其特殊性。现有条目可以不填这两个字段(缺省值为 `false`),不填不影响基本使用。

### 字段一:`is_precise_review`(精准审查标记)

- **类型**:布尔 · 默认 `false`
- **含义**:标记是否属于需要独立复扫的关键条款
- **建议标记为 true 的条目**:
  - 所有 L3 级别条目
  - 涉及核心商业条款的条目(金额、期限、核心义务)
  - 一般律师容易忽略或误判的条目
- **输出表现**:在 Word 审查报告的风险标题旁显示 `[精准审查]` 文字标签;汇总表问题概述前加 `[精准]` 前缀

### 字段二:`is_completion_check`(缺失检查标记)

- **类型**:布尔 · 默认 `false`
- **含义**:标记该条款是否属于"**合同应当包含但可能缺失**"的必要条款
- **建议标记为 true 的条目**:
  - 不可抗力条款(C046)
  - 争议解决条款(C037)
  - 数据保护协议(C059,涉及个人信息时)
  - 其他按合同类型必须包含的条款
- **输出表现**:若合同文本未出现对应条款,该项会出现在审查报告**第五章"缺失条款提示"**,并以**三列对照表**呈现建议的桥面条款

### 为什么这样设计(核心理念)

AI 做合同审查的一大风险是**无边界**——什么条款都觉得应该加。本 skill 通过 `is_completion_check` 显式标记"缺失即有意义"的条款,其他条款即使缺失也不会进入"缺失条款"章节,从根本上避免 AI 的无边界噪音。

### 向下兼容说明

- 清单中的所有条目**无需填写这两个字段**即可使用
- 如未标记这两个字段,脚本默认当作 `false` 处理
- demo-case 示例数据(`report-data.json`)已在每条 finding 中展示这两个字段的填法

## 使用说明(先读这一节)

### 一、三类标注的含义

每一个检查项都包含以下三个标注维度,请不要混淆。

**风险等级**（合同问题的严重性）

- ■ **高风险**（正红 `#FF0000`）：涉及合同效力、核心权利义务、重大经济损失或不可逆影响。不修改则不应签约。
- ■ **中风险**（标准橙 `#FF9900`）：条款存在明显不利或模糊之处，实务中常引发争议。应当协商修改。
- ■ **低风险**（正绿 `#00A650`）：规范性瑕疵或略微不利，不影响实质权利，可作为谈判让步筹码。
- ✓ **正常**：符合审查标准，无需修改。

**确认层级**（AI 判断的可靠程度，供律师决定是否需要人工复核）

- **L1 基础级**：文本表面可见的问题（大小写金额不符、错别字、编号跳号、明显的数字错误）。AI 确定性高，几乎不需要人工复核。
- **L2 中级**：需要交叉阅读或逻辑推理才能发现的问题（条款前后矛盾、程序性权利陷阱、条款组合导致的漏洞）。AI 确定性中等，建议人工复核。
- **L3 高级**：需要结合法律法规、司法实践或行业惯例判断的问题（违约金标准是否符合司法实践、特定主体资质要求、数据安全合规）。AI 确定性相对较低，必须人工复核。

**立场差异**（同一条款在不同立场下的风险方向不同）

- 每一项标注了"甲方立场""乙方立场"或"中性"。
- 标注"中性"的条款，甲方和乙方的风险判断方向一致。
- 标注立场差异的条款，审查时必须按用户指定立场执行判断。

### 二、为什么清单分层

全部 60 项按 12 个维度分组。分层的意义有三个：

第一，AI 处理分层结构的效果远好于处理一个无结构的长列表。
第二，可以针对不同场景只启用部分维度（极简审查只用 5-8 个核心维度的精简版，标准审查启用全部）。
第三，维护时只需要定位到具体维度做增量调整，不需要通读全清单。

### 三、阈值的行业分化说明

部分检查项的阈值（如预付款比例、违约金比例）在不同行业差异显著。本清单提供的默认阈值适用于一般商业合同。建筑工程、金融、IT 软件开发、货物买卖等特定行业，请在该项条目下查看"行业分化阈值"，或根据实务经验在本文件中自行调整并在迭代记录中登记。

### 四、清单外发现如何处理

审查过程中，如果 AI 发现清单未覆盖但确实存在风险的问题，应在审查报告的"清单外发现"部分单独列出，并建议用户补充到本清单。这是本清单持续进化的核心机制。

## 速查表：哪些项 AI 可独立判断，哪些需人工核实

下表帮助审查完成后快速定位需要人工重点复核的项目。

| 项目类型 | 检查项编号 | 处理方式 |
| --- | --- | --- |
| **L1 基础级**（AI 可独立确认） | C001, C013, C014, C043, C044, C045 | 可直接采信，无需复核 |
| **L2 中级**（建议人工复核） | C003, C005, C007, C008, C009, C010, C011, C015-C022, C026, C027, C030-C034, C036-C040, C046-C050, C055-C058 | 建议逐项复核 |
| **L3 高级**（必须人工复核） | C002, C004, C006, C012, C023, C024, C025, C028, C029, C035, C041, C042, C051-C054, C059, C060 | 必须逐项人工确认，特别是涉及法律适用判断的 |
| **需调用外部信息**（AI 无法独立判断） | C004（主体资格存续）、C012（单方解释权无效性）、C035（保密期限合理性）、C060（数据合规）等 | 需核实工商信息、裁判文书、最新监管规则 |

## 一、主体资格审查

### C001 · 合同主体名称一致性

- **检查项**：合同中出现的同一主体名称是否前后一致
- **判断标准**：同一主体出现两种及以上不同名称 = ■ 高风险
- **识别线索**：对比合同首部"甲乙方"信息与正文中对同一主体的指代，特别注意简称、缩写、子公司名称的混用
- **典型不触发**：合同首部约定"甲方：XX 有限公司（以下简称'甲方'或'XX 公司'）"后，全文在此两种表述之间切换 = ✓ 正常
- **修改建议**：统一为营业执照/登记证书上的全称，后续一律使用简称
- **确认层级**：L1 基础级
- **立场**：中性

### C002 · 签约主体与履约主体的一致性

- **检查项**：签约方是否具有履约能力，是否存在签约方与实际履约方不一致的情况
- **判断标准**：签约方与履约方不一致且无书面授权/委托 = ■ 高风险
- **识别线索**：正文中出现"甲方可指定关联方履行""实际履约方为 XX 公司"等表述，但未附书面授权
- **典型不触发**：合同附件中有完整的授权委托书或三方协议 = ✓ 正常
- **修改建议**：要求出具加盖公章的授权委托书，或改为三方合同结构
- **确认层级**：L3 高级（涉及主体资格和连带责任的法律判断）
- **立场差异**：
  - 甲方立场：重点关注乙方是否存在转包/分包可能
  - 乙方立场：重点关注甲方是否通过空壳公司签约规避责任

### C003 · 法定代表人或授权代表签署

- **检查项**：签署人是否为法定代表人或持有有效授权委托书
- **判断标准**：非法定代表人签署且未附授权委托书 = ■ 中风险
- **识别线索**：合同末尾签署栏"经办人""代理人""项目经理"等署名，但合同正文或附件中无授权说明
- **典型不触发**：授权委托书作为附件附上，明确授权范围和期限 = ✓ 正常
- **修改建议**：要求提供加盖公章的授权委托书并作为合同附件
- **确认层级**：L2 中级
- **立场**：中性

### C004 · 合同主体资格存续

- **检查项**：合同主体是否处于正常经营状态
- **判断标准**：主体被吊销/注销/列入经营异常名录 = ■ 高风险
- **识别线索**：AI 无法通过合同文本判断，需要外部核查
- **修改建议**：建议用户核查国家企业信用信息公示系统（gsxt.gov.cn）
- **确认层级**：L3 高级（必须人工或调用工商 API 核实）
- **立场**：中性
- **说明**：本项在审查报告中标注为"⚠️ 需外部核实"，不出具 AI 判断结论

### C005 · 印章合法性

- **检查项**：合同约定的用印要求是否明确，印章是否为正式公章
- **判断标准**：合同仅约定"加盖印章"而未限定"公章" = ■ 中风险（部门章/业务章效力可能存疑）
- **识别线索**：签署栏标注"甲方：___（印章）"而非"甲方：___（公章）"
- **典型不触发**：明确约定"加盖公章或合同专用章" = ✓ 正常
- **修改建议**：明确约定"加盖公章"或"加盖合同专用章"
- **确认层级**：L2 中级
- **立场**：中性

## 二、合同标的与范围

### C006 · 标的物或服务的明确性

- **检查项**：合同标的是否具体明确，能否唯一确定
- **判断标准**：标的描述使用"等""相关""若干""基本"等模糊表述且无附件清单补充 = ■ 中风险
- **识别线索**：出现"甲方向乙方提供咨询服务""乙方完成项目相关工作"等抽象表述，无进一步拆解
- **典型不触发**：正文描述概括、但附件详列具体清单或技术规格书 = ✓ 正常
- **修改建议**：列明具体名称、规格、数量、型号，或引用附件中的标的物清单/服务 SOW
- **确认层级**：L2 中级
- **立场**：
  - 甲方立场：倾向于明确标的以便验收
  - 乙方立场：倾向于保留一定灵活性应对变更

### C007 · 服务范围与验收标准

- **检查项**：服务类合同是否明确了服务范围边界和验收/交付标准
- **判断标准**：无验收标准或验收标准为"甲方满意""符合行业标准"等主观表述 = ■ 中风险
- **识别线索**："甲方认可""达到甲方要求""合乎行业水准"等无客观衡量尺度的条款
- **典型不触发**：约定了可量化验收指标（如响应时间、并发用户数、错误率）或引用明确的国标/行标 = ✓ 正常
- **修改建议**：约定可量化的验收指标，或引用具体的国家标准/行业标准（注明标准编号）
- **确认层级**：L2 中级
- **立场差异**：
  - 甲方立场：倾向于保留验收话语权（但过度模糊可能导致乙方拒绝履行）
  - 乙方立场：必须要求客观可验证的验收标准

### C008 · 数量与规格

- **检查项**：数量是否明确，规格参数是否完整
- **判断标准**：核心参数缺失（如无数量、无规格型号）= ■ 中风险
- **识别线索**：货物买卖合同中缺少规格型号栏位、服务合同中缺少工时/人天/席位数约定
- **典型不触发**：正文或附件中有完整参数表 = ✓ 正常
- **修改建议**：在合同正文或附件清单中列明全部核心参数
- **确认层级**：L2 中级
- **立场**：中性

### C009 · 交付/履行地点

- **检查项**：标的物交付地点或服务履行地点是否明确
- **判断标准**：未约定交付地点 = ■ 中风险（可能影响风险转移时点和管辖法院判断）
- **识别线索**：合同无"交货地点""履行地""派遣地点"等约定
- **典型不触发**：明确约定交付地址或履行地城市 = ✓ 正常
- **修改建议**：明确交付/履行地点，涉及多地履行时分别列明
- **确认层级**：L2 中级
- **立场**：中性
- **说明**：履行地会影响管辖法院判断（民诉法第 24 条），与争议解决条款联动

## 三、价款与支付

### C010 · 合同金额明确性

- **检查项**：合同总金额是否明确，大小写是否一致
- **判断标准**：
  - 大小写金额不一致 = ■ 高风险（民法典第 498 条，大写金额优先但存在法律纠纷风险）
  - 仅有小写无大写 = ■ 低风险
- **识别线索**：比对合同中所有出现金额的位置，确认大小写、币种、单位完全一致
- **典型不触发**：金额大小写一致且币种明确 = ✓ 正常
- **修改建议**：统一大小写金额，明确币种（人民币/美元/欧元等）
- **确认层级**：L1 基础级
- **立场**：中性

### C011 · 付款节点与条件

- **检查项**：付款时间、付款条件、付款比例是否明确
- **判断标准**：无明确付款时间节点（如"适时支付""尽快支付""及时支付"）= ■ 中风险
- **识别线索**：出现"收到发票后付款"但未约定天数；"项目完成后付款"但未约定完成标准
- **典型不触发**：约定具体日期或触发事件+明确天数（如"验收合格后 15 个工作日内"）= ✓ 正常
- **修改建议**：约定具体的日期或"触发事件 + 天数"结构
- **确认层级**：L2 中级
- **立场差异**：
  - 甲方立场：倾向于"验收合格后付款"
  - 乙方立场：倾向于约定具体日期或较短的付款触发期

### C012 · 预付款比例

- **检查项**：预付款占合同总金额的比例是否合理
- **判断标准（甲方立场）**：预付款超过合同总金额 50% = ■ 中风险；超过 70% = ■ 高风险
- **判断标准（乙方立场）**：预付款低于合同总金额 20% = ■ 中风险（资金压力）
- **行业分化阈值**：
  - 建筑工程：甲方立场 30% 以下为健康，超过 40% 需关注（《建设工程价款结算暂行办法》参考）
  - 货物买卖：甲方立场 30%-50% 为常见，超过 70% 高风险
  - 软件开发/技术服务：30% 签约 + 30% 中期 + 40% 验收是常见结构，偏离过大需关注
  - 咨询服务：预付比例通常高于货物买卖，可达 50%-70%
- **识别线索**：合同付款条款中"签约后 X 个工作日内支付总金额 X%"的表述
- **修改建议**：调整至行业惯例区间，或要求对方提供履约保函冲抵超额预付
- **确认层级**：L3 高级（需结合行业惯例判断）
- **立场**：已在判断标准中分立

### C013 · 尾款支付条件

- **检查项**：尾款支付是否与验收挂钩，是否有明确时限
- **判断标准**：尾款支付无时限约束 = ■ 中风险
- **识别线索**："剩余款项在项目完成后支付""尾款在合同履行完毕后支付"等无明确日期的表述
- **典型不触发**：约定"验收合格后 X 个工作日内支付尾款" = ✓ 正常
- **修改建议**：明确"验收合格后 X 个工作日内"支付尾款
- **确认层级**：L2 中级
- **立场差异**：
  - 甲方立场：倾向于延长尾款支付时间或与质保期挂钩
  - 乙方立场：应争取验收后短期（通常 15-30 日）支付

### C014 · 税费承担

- **检查项**：合同金额是否含税，税费由哪方承担是否明确
- **判断标准**：未约定含税/不含税 = ■ 中风险（可能引发实际成本争议）
- **识别线索**：金额数字后无"（含税）""（不含税）"的备注，或合同中无税费承担条款
- **典型不触发**：明确约定"合同金额含 X% 增值税，由乙方开具增值税专用发票" = ✓ 正常
- **修改建议**：明确含税金额及税率，约定发票类型（增值税专用发票 / 普通发票）
- **确认层级**：L1 基础级
- **立场**：中性

### C015 · 价格调整机制

- **检查项**：长期合同是否有价格调整机制
- **判断标准**：合同期限超过 1 年且无价格调整条款 = ■ 低风险（提示关注）
- **识别线索**：合同期限 1 年以上但价款条款中无"调价""价格调整""CPI 联动"等机制
- **典型不触发**：合同期限 1 年以内 = ✓ 正常；或有明确的调价公式 = ✓ 正常
- **修改建议**：对长期合同建议约定价格调整机制（原材料联动、CPI 联动、年度协商等）
- **确认层级**：L2 中级
- **立场差异**：
  - 甲方立场：倾向于锁定价格
  - 乙方立场：应争取价格调整权（特别是原材料或汇率敏感行业）

### C016 · 逾期付款利息

- **检查项**：是否约定逾期付款的利息或违约金
- **判断标准**：未约定逾期付款责任 = ■ 低风险（提示关注）
- **识别线索**：付款条款中无"逾期付款""滞纳金""逾期利息"等表述
- **典型不触发**：约定逾期付款按日利率 X 计算 = ✓ 正常
- **修改建议**：约定逾期付款按日万分之三至万分之五计算违约金
- **确认层级**：L2 中级
- **立场**：
  - 甲方立场：作为付款方，倾向于不约定或约定较低利率
  - 乙方立场：作为收款方，应争取明确的逾期利息条款

---

## 四、权利与义务

### C017 · 权利义务对等性

- **检查项**：双方权利义务是否大致对等
- **判断标准**：一方承担全部或绝大部分义务而对方仅享有权利 = ■ 中风险
- **识别线索**：合同条款中"甲方应当……""甲方有义务……"的数量远多于乙方，或反之
- **典型不触发**：整体权利义务分布相对平衡 = ✓ 正常
- **修改建议**：整体评估后向对方提出义务再平衡的要求
- **确认层级**：L2 中级（需整体评估，非单条判断）
- **立场**：中性
- **说明**：此项需整体评估，不能仅看单个条款

### C018 · 单方权利条款

- **检查项**：是否存在一方享有单方决定权的条款（如单方解释权、单方调价权、单方变更条款）
- **判断标准**：
  - "本合同最终解释权归 X 方所有" = ■ 高风险（违反公平原则，实务中可能被认定无效）
  - 一方有权单方变更合同条款 = ■ 高风险
  - 一方有权单方决定价格调整 = ■ 中风险
- **识别线索**：出现"最终解释权""单方变更""有权调整"等表述
- **典型不触发**：所有变更需双方书面协商一致 = ✓ 正常
- **修改建议**：删除单方解释权条款；单方变更条款改为"经双方书面协商一致"
- **确认层级**：L3 高级
- **立场**：中性（通常对任何一方都不利，除非己方为优势地位方）

### C019 · 通知义务

- **检查项**：重要事项的通知方式和时限是否明确
- **判断标准**：未约定通知方式或仅约定"口头通知" = ■ 低风险（但举证困难）
- **识别线索**：合同中无"通知""送达""书面通知"等表述，或仅约定口头形式
- **典型不触发**：约定书面通知（含邮件、EMS、专人送达）并明确送达地址和视为送达条件 = ✓ 正常
- **修改建议**：约定书面通知（含邮件），明确送达地址、联系人、邮箱、视为送达的条件
- **确认层级**：L2 中级
- **立场**：中性（双方均需)

### C020 · 协助义务

- **检查项**：合同履行中的协助义务是否明确
- **判断标准**：乙方履约需要甲方协助（如提供资料、安排场地、授予权限）但未约定具体协助内容和时限 = ■ 中风险
- **识别线索**：服务合同或技术合同中"甲方应提供必要的协助"但无具体清单
- **典型不触发**：协助义务以清单形式附件列明 = ✓ 正常
- **修改建议**：附件列明具体协助事项、时限和未按时协助的后果
- **确认层级**：L2 中级
- **立场差异**：
  - 甲方立场：倾向于模糊协助义务
  - 乙方立场：必须争取具体化并约定甲方不配合的免责条款

## 五、违约责任

### C021 · 违约金比例

- **检查项**：违约金占合同总金额的比例是否合理
- **判断标准**：
  - 违约金超过合同总金额 30% = ■ 高风险（民法典第 585 条，法院可能酌减）
  - 违约金低于合同总金额 5% = ■ 低风险（可能不足以覆盖实际损失）
- **行业分化阈值**：
  - 一般商业合同：10%-30% 为合理区间
  - 建筑工程：通常不超过 20%
  - 销售合同：可达 20%-30%
  - 涉及核心商业秘密或知识产权的合同：可约定较高违约金，但仍需结合实际损失合理性
- **识别线索**：违约责任条款中的百分比数值
- **典型不触发**：比例在 10%-30% 区间 = ✓ 正常
- **修改建议**：调整至合理区间；如对方主张更高比例，要求对应高损失证据
- **确认层级**：L3 高级（需结合司法实践判断）
- **立场差异**：
  - 甲方立场：对方违约金过低为风险
  - 乙方立场：我方违约金过高为风险

### C022 · 违约金对等性

- **检查项**：双方违约金标准是否对等
- **判断标准**：双方违约金比例差异超过 2 倍 = ■ 中风险（如甲方违约 5%，乙方违约 20%）
- **识别线索**：违约责任条款中双方违约金比例并列出现，数值不对称
- **典型不触发**：双方违约金比例基本对等，或虽不对等但有合理商业解释（如保证金机制对冲）= ✓ 正常
- **修改建议**：协商统一违约金标准，或根据违约情形差异化设置但整体平衡
- **确认层级**：L2 中级
- **立场差异**：
  - 处于劣势一方应重点争取

### C023 · 逾期履行违约金日率

- **检查项**：逾期履行（交付延迟、服务中断等）的违约金日率是否合理
- **判断标准**：
  - 日违约金率超过万分之五 = ■ 中风险
  - 日违约金率超过万分之十 = ■ 高风险
- **参考标准**：常见约定为日万分之三至万分之五
- **识别线索**：违约条款中"每逾期一日，按合同总金额 X% 支付违约金"的数值
- **典型不触发**：日率在万分之三至万分之五区间 = ✓ 正常
- **修改建议**：调整至行业合理区间
- **确认层级**：L3 高级
- **立场差异**：
  - 甲方立场：对乙方的逾期违约金过低为风险
  - 乙方立场：我方逾期违约金过高为风险

### C024 · 违约责任上限（责任 Cap）

- **检查项**：是否约定了违约责任的总额上限
- **判断标准**：无违约责任上限 = ■ 中风险（理论上无限责任）
- **行业分化阈值**：
  - 常见责任上限：合同总金额的 100%（即全额上限）
  - 宽松约定：合同总金额的 1-3 倍
  - 严苛约定：上限为已支付款项（对乙方极为不利）
  - 间接损失、利润损失通常应明确排除
- **识别线索**：合同中搜索"责任上限""最高不超过""累计责任"等表述
- **典型不触发**：明确约定了合理上限（如不超过合同总金额）= ✓ 正常
- **修改建议**：约定责任上限为合同总金额；排除间接损失、利润损失、商誉损失的赔偿
- **确认层级**：L3 高级
- **立场差异**：
  - 甲方立场：倾向于不设上限或设置较高上限
  - 乙方立场：必须争取设定上限（通常为合同总金额），并排除间接损失

### C025 · 连带责任

- **检查项**：是否存在无限连带责任条款
- **判断标准**：存在无限连带责任且无合理限制 = ■ 高风险
- **识别线索**：合同中出现"承担连带责任""连带清偿""连带保证"等表述，但无范围、期限限制
- **典型不触发**：连带责任限定了具体范围、金额上限和期限 = ✓ 正常；或根本无连带责任条款 = ✓ 正常
- **修改建议**：限定连带责任的范围（仅限主债务本金）、金额（不超过 X 元）和期限（如保证期间 2 年）
- **确认层级**：L3 高级
- **立场差异**：
  - 甲方立场：作为债权方可能乐于保留
  - 乙方立场：必须限制或排除连带责任

### C026 · 违约解除权

- **检查项**：违约解除权的触发条件和程序是否合理
- **判断标准**：
  - 一方轻微违约即可触发另一方解除权 = ■ 中风险
  - 解除权无催告期（直接解除）= ■ 中风险
- **识别线索**：出现"一旦违约即有权解除""任何违反即可解除"等严苛表述，无催告机制
- **典型不触发**：解除权触发条件为"严重违约"或"根本违约"，且设有合理催告期 = ✓ 正常
- **修改建议**：解除权限于"根本违约"情形；设定 15-30 日催告期；明确通知程序
- **确认层级**：L2 中级
- **立场差异**：
  - 甲方立场：倾向于保留宽泛的解除权
  - 乙方立场：应限制对方解除权至"根本违约"情形

### C027 · 违约赔偿与实际损失的关系

- **检查项**：违约金与实际损失的关系是否明确
- **判断标准**：违约金过高（超 30%）且未允许根据实际损失调整 = ■ 高风险（民法典第 585 条）
- **识别线索**：违约金条款过高且附加"无论实际损失多少"等排除性表述
- **典型不触发**：允许一方主张违约金过分高于实际损失时调整 = ✓ 正常
- **修改建议**：违约金调整权不可排除（民法典第 585 条第 2 款为强制性规定）
- **确认层级**：L3 高级
- **立场**：中性

## 六、知识产权

### C028 · 知识产权归属

- **检查项**：合同履行过程中产生的知识产权归属是否明确
- **判断标准**：未约定合同履行中产生的知识产权归属 = ■ 中风险
- **识别线索**：涉及定制开发、研发、设计、创作的合同中无 IP 归属条款
- **典型不触发**：明确约定新产生 IP 归属某一方，或共有（明确共有份额和行使方式）= ✓ 正常
- **修改建议**：明确约定新产生 IP 的归属（建议独占、非独占、共有）、行使方式、授权范围
- **确认层级**：L3 高级
- **立场差异**：
  - 甲方（委托方）：通常要求新产生 IP 归甲方所有
  - 乙方（开发方）：应争取保留基础技术、通用模块的权利，或争取继续使用权

### C029 · 预有知识产权

- **检查项**：双方各自预有的知识产权是否做了明确排除
- **判断标准**：未区分预有 IP 和新产生 IP = ■ 中风险
- **识别线索**：IP 条款笼统规定"本项目涉及的所有知识产权归甲方所有"但未排除乙方先前成果
- **典型不触发**：明确"乙方先前已有的技术、工具、方法论仍归乙方所有"= ✓ 正常
- **修改建议**：明确约定各方预有知识产权仍归各方所有，甲方对预有 IP 享有项目范围内的使用权
- **确认层级**：L2 中级
- **立场差异**：
  - 乙方尤其需要关注，防止过宽的 IP 归属条款吞噬基础能力

### C030 · 知识产权侵权担保与免责

- **检查项**：是否约定了知识产权不侵权的保证和侵权时的责任承担
- **判断标准**：
  - 无知识产权侵权担保条款 = ■ 低风险（提示关注）
  - 仅一方提供侵权担保而另一方未提供 = ■ 中风险
- **识别线索**：IP 条款中无"保证不侵犯第三方权利""因侵权导致的损失由 X 方承担"等表述
- **典型不触发**：双方对各自提供的 IP 均承担不侵权担保，约定侵权的免责限制 = ✓ 正常
- **修改建议**：约定双向 IP 侵权担保；设定担保的例外情形（如对方指示导致的侵权）；约定侵权通知、抗辩配合、损失承担机制
- **确认层级**：L2 中级
- **立场**：中性

### C031 · 开源软件与第三方组件合规

- **检查项**：涉及软件交付的合同是否约定了开源软件声明和第三方组件合规
- **判断标准**：软件开发/技术合同未约定开源软件清单和合规义务 = ■ 中风险
- **识别线索**：技术开发、软件许可、SaaS 服务合同中无"开源软件""第三方组件"相关条款
- **典型不触发**：约定乙方提供开源软件清单、遵守许可协议、不引入 Copyleft 风险 = ✓ 正常
- **修改建议**：约定乙方提供开源软件声明（BOM 清单）、禁止使用 GPL 类 Copyleft 开源组件（除非甲方书面同意）
- **确认层级**：L3 高级
- **立场差异**：
  - 甲方（采购方）立场：必须要求 BOM 清单和合规承诺
  - 乙方（供应方）立场：注意不要对整个开源生态做过宽的无限承诺

## 七、保密条款

### C032 · 保密信息的定义范围

- **检查项**：保密信息的范围是否明确
- **判断标准**：
  - 保密范围表述为"与本合同相关的一切信息"= ■ 低风险（范围过宽但实务中常见）
  - 保密范围完全缺失 = ■ 中风险
- **识别线索**：保密条款开头定义段的表述
- **典型不触发**：列明了保密信息的具体类别（技术信息、商业信息、经营信息等）和标识要求（标注"保密"）= ✓ 正常
- **修改建议**：明确列举保密信息类别，并约定识别方式（书面标注"保密"或口头告知后 X 日内书面确认）
- **确认层级**：L2 中级
- **立场**：中性

### C033 · 保密信息的排除（非保密信息）

- **检查项**：哪些信息明确不属于保密信息
- **判断标准**：未约定排除条款 = ■ 中风险（可能导致公开信息也被纳入保密义务）
- **识别线索**：保密条款中缺少"下列情形不属于保密信息"的列举
- **典型不触发**：明确排除五类信息 = ✓ 正常：
  - 已经公开的信息
  - 接收方在接收前已知的信息
  - 从第三方合法获取且无保密义务的信息
  - 接收方独立开发的信息
  - 经披露方书面同意公开的信息
- **修改建议**：补充上述五类标准排除条款
- **确认层级**：L2 中级
- **立场**：中性（接收方更为关键）

### C034 · 保密义务对等性

- **检查项**：保密义务是否仅约束一方
- **判断标准**：仅一方承担保密义务（单向保密）= ■ 中风险（除非系单向信息流）
- **识别线索**：保密条款中只写"乙方应保密甲方的……"或反之
- **典型不触发**：
  - 双向保密约定 = ✓ 正常
  - NDA 单向保密但确为单向信息流（如尽调 NDA）= ✓ 正常
- **修改建议**：一般商业合作协议约定双向保密义务
- **确认层级**：L2 中级
- **立场差异**：
  - 弱势方或信息少的一方尤其需要关注单向保密条款

### C035 · 保密期限

- **检查项**：保密义务的持续期限
- **判断标准**：
  - 保密期限超过合同期限 5 年以上 = ■ 低风险（提示关注）
  - 永久保密 = ■ 中风险
- **行业分化阈值**：
  - 一般商业合同：合同终止后 2-3 年为常见
  - 涉及核心技术秘密的合同：5-10 年合理
  - 金融、医药等高敏感行业：可达 10 年以上，但一般不应永久
- **识别线索**：保密条款中"保密期限""持续期间""本条款持续有效"等表述
- **典型不触发**：合理期限范围内 = ✓ 正常
- **修改建议**：除商业秘密本身永久保密外，一般信息约定合同终止后 2-5 年为宜
- **确认层级**：L3 高级
- **立场**：
  - 披露方：倾向于较长保密期
  - 接收方：应争取合理缩短

### C036 · 保密义务违约责任

- **检查项**：违反保密义务的后果是否明确
- **判断标准**：保密条款存在但未约定违约责任 = ■ 中风险
- **识别线索**：保密义务段落结束后无对应的违约金或损害赔偿约定
- **典型不触发**：约定了明确的违约金或赔偿机制 = ✓ 正常
- **修改建议**：约定违反保密义务的违约金（固定金额或按合同金额比例），明确披露方可要求停止披露、销毁已披露信息等救济
- **确认层级**：L2 中级
- **立场**：中性

## 八、争议解决

### C037 · 争议解决方式的约定

- **检查项**：是否约定了争议解决方式（诉讼/仲裁）
- **判断标准**：未约定争议解决方式 = ■ 高风险（实务中争议时无明确规则）
- **识别线索**：合同末尾无"争议解决""诉讼管辖""仲裁"等条款
- **典型不触发**：明确约定为诉讼或仲裁之一 = ✓ 正常
- **修改建议**：明确约定诉讼或仲裁
- **确认层级**：L1 基础级
- **立场**：中性

### C038 · 诉讼与仲裁的排他性

- **检查项**：是否同时约定了诉讼和仲裁
- **判断标准**：同时约定诉讼和仲裁 = ■ 高风险（仲裁条款可能被认定无效，仲裁法第 16、17 条）
- **识别线索**：合同中同时出现"向 X 法院起诉"和"提交 X 仲裁委员会仲裁"的表述
- **典型不触发**：明确二选一 = ✓ 正常
- **修改建议**：明确选择其中一种方式
- **确认层级**：L1 基础级
- **立场**：中性

### C039 · 管辖法院/仲裁机构的明确性

- **检查项**：约定的管辖法院或仲裁机构是否明确、合法
- **判断标准**：
  - 约定"由双方协商确定管辖" = ■ 中风险（约定无效，实际按法定管辖）
  - 约定管辖法院与法定管辖连接点无关（如约定上海法院，但双方与合同履行均在北京）= ■ 中风险
  - 仲裁机构不存在或不规范（如"北京仲裁委员会"应准确为"北京仲裁委员会/北京国际仲裁中心"）= ■ 中风险
- **识别线索**：管辖约定中"协商""双方同意""合同签订地所在的法院"等模糊表述
- **典型不触发**：明确具体法院名称或仲裁机构全称 = ✓ 正常
- **修改建议**：明确约定具体法院（甲方/乙方所在地、合同签订地、合同履行地、标的物所在地之一）或仲裁机构全称
- **确认层级**：L2 中级
- **立场差异**：
  - 甲方立场：争取甲方所在地法院管辖
  - 乙方立场：争取乙方所在地或合同履行地管辖，或约定对双方均便利的仲裁机构

### C040 · 适用法律

- **检查项**：涉外合同是否约定了适用法律
- **判断标准**：涉外合同未约定适用法律 = ■ 中风险
- **识别线索**：合同当事人涉及外国公司、标的涉外、履行地在境外等涉外因素
- **典型不触发**：
  - 国内合同（默认适用中国法律，无需特别约定）= ✓ 正常
  - 涉外合同明确约定适用法律 = ✓ 正常
- **修改建议**：涉外合同明确约定适用法律（通常选择我方熟悉的法域或中立法域）
- **确认层级**：L3 高级
- **立场**：中性

### C041 · 仲裁语言与仲裁员选任

- **检查项**：涉外仲裁是否约定了仲裁语言和仲裁员国籍
- **判断标准**：涉外仲裁未约定仲裁语言 = ■ 中风险（可能全部使用英文等我方不熟悉的语言）
- **识别线索**：涉外仲裁条款中无"仲裁语言""仲裁员国籍"等约定
- **典型不触发**：明确约定仲裁语言和仲裁员规则 = ✓ 正常
- **修改建议**：约定仲裁语言（中文/英文/双语）、独任仲裁或三人仲裁、仲裁员国籍要求
- **确认层级**：L3 高级
- **立场**：中性

## 九、合同期限与终止

### C042 · 合同期限与生效条件

- **检查项**：合同起止时间和生效条件是否明确
- **判断标准**：
  - 无明确起止日期或起算时间不明确 = ■ 中风险
  - 生效条件（如备案、审批、第三方同意）未约定 = ■ 中风险
- **识别线索**：期限条款中"本合同期限为 X 年"但无起算日；或涉及审批的合同无"以 X 批准为生效条件"
- **典型不触发**：明确起止日期（精确到日）并约定生效条件（如需） = ✓ 正常
- **修改建议**：明确约定生效日和终止日（YYYY年MM月DD日）；涉及审批的合同约定生效条件
- **确认层级**：L2 中级
- **立场**：中性

### C043 · 自动续期条款

- **检查项**：是否有自动续期条款，续期条件是否合理
- **判断标准**：自动续期且无任何一方终止权 = ■ 中风险（可能导致"合同常年不到期"）
- **识别线索**：期限条款中"合同期满自动续期 X 年""如无异议则续期"等表述
- **典型不触发**：自动续期但设有到期前 X 日书面通知不续期机制 = ✓ 正常
- **修改建议**：约定任何一方可在到期前 30-60 日书面通知不续期
- **确认层级**：L1 基础级
- **立场**：中性

### C044 · 提前终止权

- **检查项**：提前终止的条件和程序
- **判断标准**：
  - 仅一方享有提前终止权 = ■ 中风险
  - 一方享有无条件单方终止权且对方无补偿 = ■ 高风险
- **识别线索**："甲方有权随时解除本合同""一方可提前通知终止"等表述，注意是否单边
- **典型不触发**：双方对等的终止权，或一方终止需合理补偿对方 = ✓ 正常
- **修改建议**：约定对等的终止权，或终止方给予对方合理补偿（如已投入成本的补偿）
- **确认层级**：L2 中级
- **立场差异**：
  - 甲方立场：通常希望保留较大的终止灵活性
  - 乙方立场：应争取对等的终止权或补偿机制

### C045 · 终止后的权利义务

- **检查项**：合同终止后的结算、交接、保密等后续义务是否明确
- **判断标准**：无终止后结算和交接条款 = ■ 低风险（但可能引发争议）
- **识别线索**：期限条款后无"合同终止后""合同期满后"的后续安排
- **典型不触发**：约定了结算方式、资料交接、保密义务延续等 = ✓ 正常
- **修改建议**：约定终止后的结算机制、资料/设备/文档交接清单和时限、保密义务延续期限
- **确认层级**：L2 中级
- **立场**：中性

## 十、不可抗力

### C046 · 不可抗力条款的缺失

- **检查项**：是否约定了不可抗力条款
- **判断标准**：未约定不可抗力条款 = ■ 中风险（虽有民法典第 180 条法定救济，但实务中应明确约定）
- **识别线索**：合同中无"不可抗力""force majeure"等表述
- **典型不触发**：有明确的不可抗力条款 = ✓ 正常
- **修改建议**：补充标准不可抗力条款
- **确认层级**：L1 基础级
- **立场**：中性

### C047 · 不可抗力的定义

- **检查项**：不可抗力事件的范围是否明确，是否包含常见情形
- **判断标准**：
  - 不可抗力定义过窄（仅列举自然灾害）= ■ 低风险
  - 将一方可预见或可避免的情形纳入不可抗力 = ■ 中风险（与法律定义相悖）
- **识别线索**：不可抗力定义段列举的事件范围
- **典型不触发**：列明自然灾害、社会异常事件（战争、罢工、政府行为）、重大疫情等常见情形，并设置兜底条款 = ✓ 正常
- **修改建议**：补充全面的事件列举 + 兜底条款（"以及其他不能预见、不能避免并不能克服的情形"）
- **确认层级**：L2 中级
- **立场**：中性

### C048 · 不可抗力的通知和证明

- **检查项**：不可抗力发生后的通知时限和证明要求
- **判断标准**：无通知时限或证明要求 = ■ 低风险
- **识别线索**：不可抗力条款中无"书面通知""X 日内""证明文件"等表述
- **典型不触发**：约定 15 日内书面通知并提供证明 = ✓ 正常
- **修改建议**：约定不可抗力发生后 15 日内书面通知，并在 30 日内提供相关机构出具的证明
- **确认层级**：L2 中级
- **立场**：
  - 主张不可抗力的一方：应接受合理的通知和证明义务
  - 相对方：应要求及时通知和书面证明

### C049 · 不可抗力的终止机制

- **检查项**：不可抗力持续超过一定期限后的处理方式
- **判断标准**：未约定不可抗力持续超期后的终止权 = ■ 低风险
- **识别线索**：不可抗力条款中无"持续超过 X 日"的终止约定
- **典型不触发**：约定持续超过 30-90 日任一方可终止 = ✓ 正常
- **修改建议**：一般约定超过 30-90 日任一方可书面通知终止合同
- **确认层级**：L2 中级
- **立场**：中性

## 十一、送达与签署

### C050 · 送达地址确认

- **检查项**：是否约定了法定送达地址
- **判断标准**：未约定送达地址 = ■ 低风险（但诉讼中可能导致送达困难）
- **识别线索**：合同末尾无"送达地址""联系地址"确认条款
- **典型不触发**：约定了送达地址，并明确变更通知机制 = ✓ 正常
- **修改建议**：约定送达地址确认条款（《民事诉讼法》第 90 条），明确地址变更的通知义务和视为送达的条件
- **确认层级**：L2 中级
- **立场**：中性

### C051 · 签署完整性

- **检查项**：双方签章是否齐全，日期是否完整
- **判断标准**：
  - 缺少一方签章或签署日期 = ■ 高风险（合同可能未成立）
  - 签字不清晰或签章模糊 = ■ 中风险
- **识别线索**：合同末尾签署栏是否填写完整
- **典型不触发**：双方签章完整、日期齐全 = ✓ 正常
- **修改建议**：确保双方签章和日期均完整，签章清晰可辨
- **确认层级**：L1 基础级
- **立场**：中性

### C052 · 骑缝章与页码

- **检查项**：多页合同是否加盖骑缝章，是否有连续页码
- **判断标准**：
  - 多页合同无骑缝章且无页码 = ■ 低风险（但存在换页风险）
  - 有页码但无骑缝章 = ✓ 正常 可接受
- **识别线索**：多页合同的页面格式
- **修改建议**：加盖骑缝章；加注连续页码（第 X 页，共 Y 页）
- **确认层级**：L1 基础级
- **立场**：中性

### C053 · 电子签名

- **检查项**：电子签署合同是否符合电子签名法要求
- **判断标准**：使用了不可靠电子签名（如 PDF 插入签名图片）= ■ 中风险（证明力较弱）
- **识别线索**：合同以电子形式签署，签署方式和平台
- **典型不触发**：使用符合《电子签名法》的可靠电子签名（如通过权威 CA 机构认证的签章服务）= ✓ 正常
- **修改建议**：使用符合《电子签名法》的可靠电子签名服务
- **确认层级**：L3 高级
- **立场**：中性

## 十二、其他常见条款

### C054 · 担保条款

- **检查项**：是否涉及担保，担保方式和范围是否明确
- **判断标准**：
  - 担保范围约定为"承担一切责任""全部债务" = ■ 高风险
  - 担保期限未明确 = ■ 中风险
  - 担保方式不明确（混淆保证/抵押/质押）= ■ 中风险
- **识别线索**：合同中的保证、抵押、质押条款
- **典型不触发**：明确担保方式、担保范围、担保金额、担保期限 = ✓ 正常
- **修改建议**：明确担保方式；明确担保范围（主债务本金、利息、违约金、实现债权费用）；约定担保期限（民法典第 692 条，约定不明视为主债务履行期届满之日起 6 个月）
- **确认层级**：L3 高级
- **立场**：中性（担保人一方尤其需要严格审查）

### C055 · 保险条款

- **检查项**：是否约定了保险要求
- **判断标准**：高风险业务（工程、运输、跨境物流等）未约定保险 = ■ 中风险
- **识别线索**：合同业务类型是否属于高保险需求，是否有对应保险约定
- **典型不触发**：约定了保险种类、金额、受益人、免赔额 = ✓ 正常
- **修改建议**：根据业务类型约定必要的保险（工程保险、货运保险、职业责任险等）
- **确认层级**：L2 中级
- **立场差异**：
  - 根据具体业务分析谁应投保及受益人

### C056 · 合规与反腐败条款

- **检查项**：是否约定了遵守法律法规的义务和反腐败条款
- **判断标准**：
  - 涉外合同或涉政府项目未约定反腐败条款 = ■ 中风险
  - 常规商业合同无合规条款 = ■ 低风险
- **识别线索**：涉外、国企、上市公司相关合同的合规条款
- **典型不触发**：约定了反腐败、反贿赂、合规承诺 = ✓ 正常
- **修改建议**：涉外和敏感主体合同补充反腐败条款（参考 FCPA、反不正当竞争法）
- **确认层级**：L2 中级
- **立场**：中性

### C057 · 转包/分包

- **检查项**：是否允许转包或分包，条件是否明确
- **判断标准**：
  - 未约定转包/分包限制 = ■ 低风险（但甲方立场应关注）
  - 允许无条件转包 = ■ 中风险（对甲方）
- **识别线索**：合同中"转包""分包""委托第三方"等表述
- **典型不触发**：明确限制转包（除非书面同意）、允许分包但需提前通知 = ✓ 正常
- **修改建议**：
  - 甲方立场：限制转包，允许特定分包但需书面同意
  - 乙方立场：争取合理的分包权
- **确认层级**：L2 中级
- **立场差异**：
  - 甲方立场：通常应限制转包/分包
  - 乙方立场：应争取合理的分包权

### C058 · 陈述与保证

- **检查项**：重要合同是否有陈述与保证条款，保证事项是否明确
- **判断标准**：重大合同（金额大、期限长、涉及重要交易）无陈述与保证 = ■ 中风险
- **识别线索**：投资协议、并购协议、大额采购协议中的陈述与保证段落
- **典型不触发**：有完整的陈述与保证条款 = ✓ 正常
- **修改建议**：补充主体资格、财务状况、无重大诉讼、无重大违法记录等陈述与保证
- **确认层级**：L3 高级
- **立场差异**：
  - 受领陈述方（通常是付款方）：要求更详尽的陈述与保证
  - 做出陈述方：控制陈述范围，增加"据知悉""在本人所知范围内"等限定

### C059 · 数据保护与个人信息

- **检查项**：涉及数据处理或个人信息的合同是否有数据保护条款
- **判断标准**：
  - 涉及个人信息处理但无数据保护条款 = ■ 高风险（《个人信息保护法》下的合规要求）
  - 涉及重要数据或跨境传输未约定安全措施 = ■ 高风险（《数据安全法》《数据出境安全评估办法》）
  - 一般商业合同涉及少量个人信息但无数据保护条款 = ■ 中风险
- **识别线索**：合同涉及客户信息、员工信息、用户数据、运营数据、交易数据等
- **典型不触发**：有完整的数据处理协议或 DPA 附件 = ✓ 正常
- **修改建议**：
  - 签订数据处理协议（DPA）作为附件
  - 明确数据处理目的、方式、期限、安全措施
  - 约定数据删除/返还机制
  - 跨境传输需符合《数据出境安全评估办法》或通过个保认证
- **确认层级**：L3 高级
- **立场**：中性（双方都需要关注合规责任分配）

### C060 · 算法与 AI 合规（新兴条款）

- **检查项**：涉及算法服务、AI 产品、自动化决策的合同是否约定算法合规义务
- **判断标准**：
  - 涉及算法推荐、生成式 AI、深度合成服务但无合规条款 = ■ 中风险
  - 涉及自动化决策（如信用评分、智能招聘）未约定人工干预机制 = ■ 中风险
- **识别线索**：合同涉及算法推荐、AIGC、深度合成、智能决策、大模型 API 等
- **典型不触发**：有算法合规条款，包括备案义务、透明度、公平性、可解释性 = ✓ 正常
- **修改建议**：补充算法备案、合成内容标识、用户知情同意、可解释性要求等合规义务（参考《互联网信息服务算法推荐管理规定》《生成式人工智能服务管理暂行办法》）
- **确认层级**：L3 高级
- **立场**：中性

## 维护建议

### 对作者（缪奇川律师）

- 每办理 5 份合同审查后，回顾清单外发现，择优补入
- 每季度 review 一次行业分化阈值，根据司法实践调整（尤其是 C021 违约金、C024 责任上限）
- 每次重大法律法规更新后，检索影响的检查项，更新判断标准和相关法条引用
- 迭代后在本文件末尾登记版本号和修改内容

### 对使用者（其他法律人）

- 本清单是作者本人合同审查经验的数字化，并非万能清单
- 使用时请结合自身业务特点调整阈值（如建筑工程领域的预付款阈值、金融行业的违约金阈值）
- 建议在本清单基础上复制一份作为本地版本，保留本清单作为参考基线
- 遇到本清单未覆盖的问题，请在审查报告的"清单外发现"部分记录，并反馈给作者
